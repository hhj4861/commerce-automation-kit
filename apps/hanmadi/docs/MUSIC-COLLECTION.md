# 관리자 음악 영상 수집

관리자 `/study/admin` → **음악 관리 → YouTube 음악 수집함**.

1. 학습 언어와 곡/아티스트를 검색하거나 YouTube 주소를 넣는다. 공식 Data API로 공개·퍼가기 가능·종료된 영상인지 확인한 뒤 수집한다. 음악 카테고리 검색, 자막 있는 영상 필터, 페이지 더 보기를 지원한다. 채널명을 가수명으로 추측하지 않는다.
2. 수집함에서 공식 원곡을 미리 듣는다. 음원 파일을 추출하거나 저장하지 않는다. 국가·연령 제한이나 이후 삭제로 실제 재생이 막히면 공식 링크/플레이어 오류를 확인한다.
3. **YouTube 자막 확인 → 트랙 선택 → 가져오기**, 또는 제공받은 TXT/SRT/VTT/LRC를 선택하고 **자막 보관**. 공개 자막 표시가 다운로드 권한을 뜻하지 않는다. 자동 생성 자막은 표시되며 검수가 필요하다.
4. **이 자막으로 학습 원문 등록**으로 곡 제목·아티스트·사용권을 확인한다. 이후 기존 **AI 자료 만들기 → JEV 평가 → 사람이 검수 → 앱 게시** 흐름을 따른다. 수집만으로 학습자에게 게시되지 않는다.

이미 등록한 영상은 기존 학습 원문을 연다. 새로 수집한 자막이 게시된 학습 자료를 자동으로 덮어쓰지 않는다. 수집함에서 지워도 등록한 학습 자료와 개인 학습 기록은 유지된다. 자막 변경은 버전을 검사하므로 다른 창의 수정이나 진행 중 가져오기가 최신 원문을 덮어쓰지 않는다.

## 서버 설정

기존 `YOUTUBE_API_KEY`를 검색과 영상 확인에 사용한다. 자막 가져오기는 별도 채널 OAuth가 필요하다. **해당 영상을 수정할 수 있는 계정**이 공식 OAuth에서 `https://www.googleapis.com/auth/youtube.force-ssl` 범위를 승인한 자격을 관리자 배포의 비밀 환경변수에 설정한다.

- `YOUTUBE_CAPTIONS_CLIENT_ID`
- `YOUTUBE_CAPTIONS_CLIENT_SECRET`
- `YOUTUBE_CAPTIONS_REFRESH_TOKEN`

기존 학습자 Google 로그인이나 영상 업로드 도구의 자격을 자동으로 재사용하지 않는다. 이 PR은 연결 로그인 화면이나 자격 발급·운영 주입을 수행하지 않는다. 세 값이 없으면 UI는 ‘자막용 채널 연결 전’이라고 표시하고 파일 등록 경로를 제공한다. 자격 값은 클라이언트 응답·소스·일반 로그에 내보내지 않는다. 관리자 설정 변경 후 새 배포가 필요하다.

[공식 captions.list](https://developers.google.com/youtube/v3/docs/captions/list)는 트랙 메타데이터만 반환한다. [captions.download](https://developers.google.com/youtube/v3/docs/captions/download)는 영상 수정 권한을 요구한다. 원문 VTT를 요청하며 자동 번역을 원문으로 저장하지 않는다. 편집 권한과 학습 재사용 권한은 다르므로 기존 사용권 확인은 유지된다. 공개 곡의 임의 자막 추출, 비공식 timedtext/스크래핑, MP3 추출은 없다.

## 저장·제한

- 별도 영속 수집함 `music-video-collection:v1`; 기존 `music-catalog:v1`과 분리.
- 영상+학습 언어별 중복 방지, 최대 100건. 원문 12,000자·2~100줄·줄당 250자. 시간은 기존 음악 학습 파서의 겹치지 않는 2분 이하 구간 규칙을 따른다. 초과·겹침을 조용히 자르지 않고 수정할 오류로 반환한다.
- 공개 검색은 기존 1시간 캐시·하루 새 검색 20회 한도를 공유한다. 음악/자막 필터별 캐시는 분리한다.
- 추가 서버 한도(UTC 일): 새 영상 확인 100회, 자막 목록 40회, 자막 가져오기 20회. Google 프로젝트 할당량은 별도이며 403/quota 오류를 구분해 표시한다.
- API는 기존 `/api/study/admin/music`의 owner·동일 출처 검사를 사용한다. GET은 설정 여부만 내보낸다. 트랙은 서버에서 해당 영상의 목록과 대조한 뒤 가져온다.

## 검증

`npm test`, 타입 검사, 대상 파일 ESLint, Next 빌드. `HANMADI_E2E_ARTIFACTS=<새 산출물 경로> npm run test:music-collection`은 실제 Next 인증·API·저장소·브라우저를 사용하고 YouTube HTTP만 로컬 fixture로 대체한다. 실제 채널 자격이나 가사, 유료 AI 호출은 사용하지 않는다. `npm run test:owned-music`은 기존 검수/게시/학습 회귀 시험이다.

운영 자막 연동 확인은 승인된 자격과 해당 채널의 검증용 영상으로 별도 수행해야 한다. 성공한 모의 응답을 실제 곡 자막 확보 완료로 보고하지 않는다.
