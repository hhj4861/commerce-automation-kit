# @cak/slide-renderer — 원자 #2 (미착수)

**역할:** 이미지 슬라이드(자막·타이포그래피·BGM) 기반 초경량 숏폼 렌더러. 무거운 비디오 인코딩 대신 저비용 생성.

**상태:** 스캐폴드만. 착수 전.

## 유지 조건 (blueprint-review 재설계 문서 keep-modified)
- ✅ 슬라이드가 비디오보다 싸다는 최적화 자체는 타당(원안 유일의 기술적 타당 최적화)
- 🔧 **입력 이미지를 스크래핑이 아닌 자체촬영/라이선스 소스로 전면 교체** (이게 없으면 원자가 아니라 위법 스크래퍼)
- 🔧 AI 모델 참조 현행화 (원안의 GPT-4V는 2026-07 기준 stale)

## 절대 금지선
- ❌ 샤오홍슈/틱톡 등 타인 콘텐츠 다운로드 입력 (저작권법 §136 비친고죄)
- ❌ "인프라 최소화 = 사업비 최소화" 오도 서사

## 조합
- 입력 계약: 렌더 잡 명세 → `@cak/contracts` 에 `RenderJob` 추가 예정
- 이 원자는 `@cak/keyword-intel` 의 `KeywordSignal` 을 직접 참조하지 않는다 (사람 기획 게이트를 거친 잡만 받음)
