# 일본어 한글 발음 장음 보완 — 2026-10-03

## 문제와 변경

운영 일본어 회화에서 `氷抜きでコーヒーを一杯ください。`에 `고리누키데 코히오 ...`가 붙었다. 기존 검사는 한글 형식과 소수 오류만 확인해 장음 누락을 통과시켰다. 진단 fixture도 같은 누락을 성공 데이터로 사용하고 있었다.

- 일본어 생성 프롬프트에 장음·촉음·조사 및 문맥별 한자 읽기를 안내한다. 다른 언어의 프롬프트는 늘리지 않는다.
- 새 학습용 표기는 `코오리누키데 코오히이오 ...`처럼 장음을 모음 반복으로 드러낸다. 한국어 외래어 표기 규칙과는 다른 말하기 보조 표기다.
- 문맥이 명확한 氷 용례와 コーヒー·ビール·タクシー·ケーキ의 장음 누락을 공통 검증한다. 명시적 하이픈/콜론 장음 표기는 허용한다. 같은 단어가 반복되면 발음 횟수도 확인한다.
- 잘못된 발음은 회화·내 말 변환·양방향 번역의 기존 보정 1회를 사용한다. 오류가 계속되면 결과를 반환/저장하지 않는다. 올바른 번역의 별도 복습 후보만 잘못되면 후보를 제외한다.
- かき氷·氷点 등은 고정 한자 읽기로 치환하지 않는다. 기존 저장 표현은 자동 수정하지 않는다.

## 검증

- 전체 단위 테스트 통과 (exit 0).
- TypeScript, 변경 파일 ESLint, E2E 스크립트 문법 검사 및 diff 공백 검사 통과.
- 네 생성 경로의 오류→보정 성공, 지속 오류 최대 2회, 잘못된 복습 후보 저장 차단을 회귀 검사한다.
- 장음, 반복 단어, 반각 가타카나, 합성어 예외 및 영어 영향 없음 검사.
- 관리자 E2E의 보정 fixture를 잘못된 JSON 대신 실제 `고리누키노 코히데스네` 오류로 변경했다. 브라우저 CI 결과는 PR에서 확인한다.

## 한계와 적용 범위

알려진 발음 오류를 제한된 어휘 대조로 막는다. 임의 한자·고유명사·전체 문장 순서·모든 음절의 정확도를 보증하는 발음 사전 엔진은 아니다. 새 실제 모델 응답 품질과 운영 반영은 PR 승인·배포 후 별도 확인한다.

근거: [국제교류기금 Marugoto 표기 지침](https://marugoto.jpf.go.jp/assets/docs/teacher/resource/starter_a/spelling_rules_of_the_Roman_alphabet.pdf)은 가타카나 장음을 모음 반복으로 표시하며 コーヒー를 koohii로 제시한다. 한글 보조 표기는 앱의 학습용 표기 결정이다.
