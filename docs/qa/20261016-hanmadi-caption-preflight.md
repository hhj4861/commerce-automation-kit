# Hanmadi 자막 가져오기 사전 확인 — 2026-10-16

## 문제와 변경

운영 원문·작업의 ‘YouTube 자막 확인’이 채널 자격 미설정 상태에서도 켜져 있었다. 버튼을 누르면 기존 음악 수집함에 영상을 추가한 다음 자막 목록 단계에서 503으로 실패했다. 기존 음악 수집 화면에는 연결 여부가 있었지만 공통 원문 화면으로 전달되지 않았다.

관리자 GET과 원문 목록 GET이 기존 `musicYoutubeConfiguration()`의 비밀 없는 설정 여부만 돌려준다. 영상 찾기는 검색 전과 결과 카드에서 자막 파일 준비 필요 또는 영상별 가져오기 권한 미확인을 표시한다. 영상 수집이 자막 확보를 뜻하지 않음을 선택 목록에서도 안내한다.

원문 화면은 상태 확인 전·미연결 상태의 직접 가져오기 버튼과 실행 함수를 모두 막는다. 파일 등록 위치로 이동하면 실제 원문 파일 입력에 초점을 맞춘다. 연결된 상태의 기존 가져오기·서버 권한 검사는 유지한다.

**자동으로 가져올 수 있는 영상만 필터링했다고 주장하지 않는다.** 공개 자막이 있다는 사실은 다운로드 허용과 다르다. [YouTube 공식 captions.download](https://developers.google.com/youtube/data/reference/rest/v3/captions/download)는 영상 수정 권한을 요구한다. 이번 수정은 확보 방식과 미연결 상태를 수집 전에 드러내는 UX·실행 조건 보완이다. 새 OAuth 로그인·자격 발급·공급자 설정·스크래핑은 없다.
