## 변경

- 검토 응답을 `validateDepthReview`로 검사한 뒤, 형식/인용 오류에만 동일 대본의 검토 JSON을 최대 1회 보완한다. 또 실패하면 SCENARIO_REVIEW_INVALID로 중단한다. API/인증/네트워크 실패는 이 보완에 포함하지 않는다.
- 유효한 내용 불합격은 재검토로 합격을 유도하지 않고 기존 1회 대본 보완 경로를 유지한다. 두 번째 대본도 불합격이면 실패 항목을 error.failedChecks로 전달한다.
- 브라우저에는 고정된 7개 항목의 한국어 이름만 표시한다. 모델 자유문, CLI 진단, 인증정보는 공개 오류에 추가하지 않는다.
- 검토 JSON 보완은 검토 호출당 최대 1회다. 대본 보완은 기존 최대 1회이며 전체 작업 deadline/취소 신호는 유지된다. 최악의 경우 기존 호출 수 대비 최대 2회 검토 호출이 늘어날 수 있다.
- 검토 기준·digest·정확한 인용 확인·발행 검수·크레딧 상한을 완화하지 않는다.
