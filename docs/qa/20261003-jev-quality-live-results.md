## 발견한 중복 근거 오류

모든 중복 후보에서 LLM은 `referenceIndex=0`을 반환했다. 번호는 형식상 유효했지만, 실제 기존 자료의 해당 문장은 후보와 다른 의도였다. 아래는 원래 응답을 바꾸지 않고 내용 검토로 추가한 분석이다.

| 후보 의도 | 실제 연결된 기존 자료 | 문제 |
|---|---|---|
| 영어: 음식에 견과류가 있는지 확인 | 매운맛을 낮춰 달라는 요청 | 음식 관련이어도 요청 대상·의도가 다름 |
| 일본어: 호텔에서 짐 보관 부탁 | 길을 물어보는 표현 | 상황·행위가 다름 |
| 스페인어: 더 큰 사이즈 확인 | 선물이 맞지 않을 때 교환 가능 기간 | 크기 확인과 교환 기한은 다른 질문 |
| 영어: 카페 반려견 동반 입장 | 반대 방향 열차에서 되돌아가는 방법 | 상황·행위가 다름 |

후보들은 같은 배치의 첫 정상 후보와 실제로 중복되므로 이번 고정 라벨상 보류는 적합했다. 그러나 LLM이 제시한 기존 자료 근거는 틀렸다. 일부 응답이 “참조 0번 후보”라고 설명해 기존 자료 번호와 배치 후보 번호를 혼동했을 가능성이 있으나, 내부 원인을 확정한 것은 아니다.

권고: 참조 종류와 식별자를 분리하고, 모델이 주장한 비교 대상을 명시적으로 결합한 검증을 추가한다. **번호가 유효하다는 사실만으로 의미가 일치한다고 보지 않는다.** 이 사례를 회귀셋으로 보존하되 모델 결과를 본 뒤 이번 기대 라벨이나 임계값을 바꿔 점수를 맞추지 않는다. 개선 후 별도 미사용 자료와 사람 검수가 필요하다.
