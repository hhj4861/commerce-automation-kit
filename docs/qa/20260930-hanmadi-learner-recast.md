# 한국어 사용자 발화 → 학습 언어 표현 → 개인 복습

## 동작

- AI 대화에서 한국어/한글 음차로 입력한 내 말을 학습 언어 원문, 한글 발음, 한국어 뜻 순서로 표시한다. 네 언어(일본어·태국어·영어·스페인어) 모두 적용한다.
- 사용자가 말하려던 내용을 변환하며 상대방의 답변으로 대체하지 않는다. 도움 요청 문장은 실제 발화 의도로 바꾼다. 기존 대화 원문을 후속 맥락에 유지하고, 원문은 접힌 ‘내 입력 보기’로 확인한다.
- ‘들어보기’를 공유하며 역할 표시로 내 말과 AI 답변을 구분한다.
- 짧은 일반 표현은 계정별 내 표현에 chat 출처로 저장하고 기존 스터디 복습 큐에 반영한다. 중복은 언어별 정규화 키로 병합한다. 공용 자료·외부 모델 훈련 데이터로 등록하지 않는다.
- 내 말 자동 학습은 기본 켜짐이며 설정에서 변경한다. 기존 번역 자동 학습 설정과 독립적이다. 비활성화·삭제 중인 요청은 saveEpoch 장벽으로 재저장을 막는다.
- 개인·연락처·건강 정보는 모델의 재사용 가능 판정과 기존 결정적 필터로 제외한다. 이 판정은 휴리스틱이며 완전한 개인정보 검출을 보증하지 않는다. 표시용 문장과 저장 가능 문장을 구분한다.
- 변환 실패는 원문과 실패 설명을 보여주고 AI 응답을 유지한다. 저장 실패도 표시한다. 대화/조작 시작 요청은 가짜 학습 문장을 만들지 않는다.
- 같은 선택 모델로 AI 답변과 내 말 변환을 병렬 호출한다. 한국어가 포함된 턴은 정상 시 호출이 하나 추가된다. 형식 오류만 같은 모델로 한 번 재생성하며 인증/전송 오류로 다른 모델에 전환하지 않는다.
