# 대본 단계의 검색 범위 분리

- 목표/담당: Codex 단독. 운영 실생성의 대본 보완 중 CODEX_TIMEOUT 이후 자료 조사와 작성·검토의 도구 범위를 분리한다.
- 기준: main e9af801 (#211), 운영 ffba7b4 (#212). 사용자 승인된 #211/#212 머지·Pages 배포 완료.
- 실제 결과: 수원 서북공심돈 QA 15:38 KST 재시도는 research → scenario → review → revision → CODEX_TIMEOUT. 신규 미디어·음성·렌더·업로드 없음.
- 확인된 문제: scenarioBrief와 reviewDepth가 draftOnly를 전달하지 않아 Codex 웹 검색이 작성·보완·검토에서도 활성화돼 있었다. 개별 대본 호출 제한은 360초, 전체 작업은 900초다. 실제 CLI 출력이 보존되지 않아 추가 검색이 이번 시간 초과의 직접 원인인지는 입증하지 못했다.
- 변경: research가 있는 대본 작성·보완과 모든 독립 검토/검토 형식 보완에 draftOnly를 전달한다. researchTopic은 기존 검색을 유지하고 searched 증거도 계속 요구한다. 제공 근거 밖의 사실을 채우지 않도록 프롬프트도 일치시킨다. 기존 조사 없는 시나리오 작성 동작은 보존한다.
- 유지: 모델·추론 설정·개별/전체 제한 시간·예산·내용 검토·재시도 한도. 품질 판정을 완화하거나 미디어 생성을 강행하지 않는다.
- 완료 기준: 단계별 검색 권한/근거 유지와 보완·오류 검사 통과, 작업 upstream push, PR 준비. 실제 운영 적용은 새 PR 명시 머지 승인 후다.
- 검증: 대본 생성·보완/검토·검토 형식 보완 및 Codex·Claude 실제 spawn 도구 제한 검사 45개 통과. 검색 1회 뒤 작성/보완/검토가 같은 근거를 받으며 draftOnly=true, signal/model 유지됨을 확인했다. git diff --check 통과. 운영 시간 단축이나 전체 E2E 성공은 아직 확인하지 않았다.
