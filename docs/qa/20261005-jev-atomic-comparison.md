# JEV·Codex 고정 문항 비교 — 2026-10-05

**보완한 12개 문항에서 JEV와 Codex 모두 잠정 라벨과 같은 선택을 했다. JEV는 기존 신뢰도 기준을 적용하면 4개 통과·3개 거절·5개 보류이며, 보류 중 2개는 근거가 있는 문구였다.** 다음은 임계값을 유지하면서 근거가 있는 위치·제안 문구가 보류되는 원인을 다른 대상에서도 확인하는 것이다. 사람의 독립 라벨 검토와 대상 확장 전에는 정확도·전면 적용 여부를 결론내리지 않는다.

이번 결과는 비교 평가 기록이다. 제품 코드·운영 플래그·키·예산·컨테이너를 변경하지 않았다. PR #140의 v2.2 질문을 현재 운영 JEV 브리지에 평가 입력으로 전달했으며, v2.2 서비스 배포를 뜻하지 않는다. 브라우저부터 검색·생성까지의 통합 E2E도 아니다.

## 고정 입력과 비교 방법

[사례·출처 데이터](20261005-jev-evidence-cases.json)의 12개 항목과 세 공식 발췌를 재사용했다. 주소는 시설 본문, 도서관 설명은 2025-10-28 기사 시점이며, 지붕의 음향 목적은 제공한 발췌에 없다. 라벨·해설·출처의 supportScope/limits·다른 모델 답변은 입력에서 제외했다. 검사 문구와 근거는 바꾸지 않았고 문항 ID는 sample-001~012로 가렸다. 이전 잘못된 전체 후보 accepted 기대값은 채점하지 않았다.

- 출처/루브릭/문구/순서/호출 수/임계값을 실호출 전에 고정했다. 데이터 SHA-256: `e38b12edc1b1f5e4979fb7a4128c3598a90f3a3a592eb72b5f93c1d024cb3674`.
- JEV `jev-1.13.0`: 12개 질문과 공통 근거를 한 요청으로 평가, 기존 discovery 전용 키 사용.
- Codex: 같은 질문·기준·근거를 한 프롬프트로 평가. 기존 ChatGPT 로그인, CLI `codex-cli 0.160.0`, 설정 모델 `gpt-6-astra`, 추론 설정 `high`. 응답 이벤트에 실제 모델명이 없어 별도 확인된 모델명으로 표시하지 않는다. OpenAI API 키 환경변수는 전달하지 않았다.
- JEV는 질문별 문맥을 평가하고 Codex는 전체 질문과 CLI 시스템 문맥을 함께 본다. 서로 다른 출력 형식·토큰·추론 예산이며 완전히 같은 실행 조건은 아니다. Codex에는 수치 신뢰도를 요구하지 않았다.
- 두 경로 모두 애플리케이션 호출 1회, 재시도 0회. Codex는 읽기 전용이며 외부 도구·검색을 비활성화했다. 반환 이벤트에 도구 실행이 없고 searched=false였다.

JEV 기준은 confidence ≥0.8, 선택 확률 ≥0.8, 2위와 차이 ≥0.2이며 uncertain은 항상 보류다. 위 표의 통과/거절/보류는 이 조건을 **개별 필드에 오프라인 적용한 결과**다. 실제 후보는 다른 모든 검사도 필요하므로 후보 전체 accepted/held/rejected와 다르다.

Codex는 전역 설정의 미인식 항목 `mcp_servers.socar-grafana.oauth_client_id` 경고 2개를 반환했다. 원래 진단을 기록하고, 유효 JSON·완료 이벤트·exit 0 및 외부 도구 미실행을 별도로 확인했다. 전역 설정은 수정하지 않았다.
