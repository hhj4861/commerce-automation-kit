# Hanmadi AI 회화 형식·언어 회귀 검증

## 원인과 수정

운영 일본어 회화에서 `곤니치와, 현종데스요` 입력 후 원문 자리에 한국어가 표시되는 문제를 실제 브라우저에서 재현했다. 신고된 JSON 형식 오류는 이번 브라우저 호출에서는 재현되지 않았다. 기존 요청은 프롬프트로만 JSON을 요구했고, 원문의 언어를 검사하지 않았으며, 이전 AI 답변을 세 필드 구분 없이 일반 텍스트로 전달했다.

수정은 엄격한 JSON schema와 필드별 언어 설명, 원문/발음/뜻 분리 지시, 문자 종류 검증, 구조화된 이전 답변 전달이다. 모델이 형식 또는 언어 검사를 통과하지 못하면 같은 선택 모델로 한 번 재생성한다. 두 번째도 실패하면 오류를 표시하며 잘못된 답변은 화면·학습 데이터에 반영하지 않는다. 통신·인증 오류에는 재생성이나 다른 모델 전환을 하지 않는다. 두 번의 최대 30초 요청을 위해 서버 실행 한도와 회화 요청의 브라우저 대기 한도를 90초로 늘렸다.

## 실제 모델 검증

운영 LiteLLM 컨테이너의 `hanmadi-chat` 별칭에 수정 프롬프트/schema를 직접 보냈다. 비밀은 컨테이너 메모리에서만 읽고 출력·저장하지 않았다. 서버 설정과 운영 앱 코드는 변경하지 않았다.

프롬프트만 강화하고 schema 필드 설명이 없는 첫 실험은 여전히 한국어 원문을 반환했다. 필드별 언어 설명을 넣은 최종 요청에서는 다음 일본어 응답을 받았다(HTTP 200, finish_reason=stop).

- 원문: こんにちは、ヒョンジョンさん！日本は好きですか？
- 발음: 곤니치와, 횬존상! 니혼와 스키데스카?
- 뜻: 안녕하세요, 현종 씨! 일본을 좋아하시나요? (네, 좋아해요 라고 대답해 보세요)

태국어·영어·스페인어도 각 원어 문자와 한글 발음, 한국어 뜻을 반환했다. 한글 발음은 근사 표기이며 문자 검사는 의미·발음 정확성을 완전히 보장하지 않는다. 영어와 스페인어는 같은 라틴 문자를 사용하므로 문자 검사만으로 둘을 구별하지 않는다.

## 자동 검증

- 단위 테스트 51개 통과. 빌드·타입 검사 통과. ESLint 오류 0개(기존 경고 4개).
- 단위 회귀: 네 언어 원문 허용, 신고된 한국어 원문 거부, 잘못된 필드/문자/길이 거부, JSON·언어 실패의 1회 복구, 반복 실패와 인증/통신 실패의 중단.
- 브라우저 E2E: upstream fixture가 첫 응답에 한국어 원문을 보내도록 하고 신고 문장을 입력하여 정상 재생성/표시 확인. 실제 API 요청의 schema와 이전 assistant JSON도 검사. 로그인·학습·번역·개인 모델·Codex/Claude 연결 흐름 포함.
- 실제 OAuth 신규 승인은 수행하지 않았다. 브라우저 E2E 공급자는 fixture이며 위 실제 LiteLLM 호출과 구분한다.
