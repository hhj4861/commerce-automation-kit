## 추가 발견 및 후속 수정

실제 재생 시 학습/AI의 0.85배속 설정이 1배속으로 초기화됨을 발견했다. 음원 로딩이 `playbackRate`를 `defaultPlaybackRate`로 되돌리는 것이 원인이다. Chrome 회귀 테스트에 0.85 배속을 넣자 실제 `1 !== 0.85`로 실패했다.

후속 변경은 `defaultPlaybackRate`도 설정한다. 수정 후 실제 Chrome 음성 테스트 exit 0, 스트리밍/캐시/MSE 미지원 경로의 학습 배속 0.85 및 번역 배속 1 확인. 앱 디렉터리에서 ESLint와 TypeScript 검사 통과. 스트리밍·브라우저 캐시·MSE 미지원 blob 재생 모두 0.85배속 유지, 번역은 1배속 유지하는 실제 오디오 회귀 테스트를 추가한다. 이 후속 수정은 **PR #101 운영 배포에 포함되지 않으며 별도 PR 머지·배포 승인이 필요**하다.
