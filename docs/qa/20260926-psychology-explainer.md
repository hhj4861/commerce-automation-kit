- UI, 기존 프로젝트, 영상 길이 제한(숏폼 180초/롱폼 600초), 과금, 인증, 저장 계약은 변경하지 않는다.

## 동작

- 추천과 시나리오가 함께 사용하는 `editorialGuide`에 심리학 해설 기준을 추가했다.
- 질문 → 구체적 사례 → 행동 관찰 → 쉬운 원리 설명 → 다른 해석·적용 한계 → 선택 변화로 연결한다.
- 숏폼 및 120초 미만 롱폼은 질문·사례 하나, 120~299초 롱폼은 1~2개 소주제, 300~599초는 2~3개, 600초는 3~5개 소주제를 편집 가이드로 제공한다. 개수는 결과를 강제하는 검증 규칙이 아니다.
- 도입의 상황을 다시 이해하는 순간을 킬링파트로 만들고, 말할 내용을 먼저 완성한 뒤 보조 화면으로 나눈다. 장면별로 인물·공간·화풍 정보를 포함해 개별 미디어 생성에도 이어지게 한다.
- 사용자 명시적 연출 요청을 우선하고, 다른 카테고리에 심리학 구조를 적용하지 않는다.
- 심리학 시나리오의 일반적인 이야기 지시를 해설 구성 지시로 바꿨다. 기존 storyArc 검증은 유지한다.
