# Hanmadi 전체 상황·레벨 커리큘럼 개선

## 문제와 변경

기존 `lessonPhrases()`는 클럽·바 외 7개 상황에서 레벨별 첫 문장 뒤에 같은 상황 문장과 공통 문장을 붙였다. 상황당 4단계 × 10문장(40회 노출)이지만 실제 고유 문장은 13개였다. 한 언어 전체 320회 노출에서 고유 문장은 일본어·태국어·영어 128개, 스페인어 130개였다.

이제 7개 상황의 28개 수업에 각각 독립된 목표·장면·10개 발화 의도와 한국어 원문을 작성했다. 이를 4개 언어로 옮긴 1,120개 표현과 기존 클럽·바 160개 표현을 합쳐 총 1,280개 표현을 제공한다. 언어당 320개 원어 문장은 공백·구두점·대소문자·문자폭을 정규화해도 중복되지 않는다. 같은 상황에서 기본 문형을 재사용하는 것은 허용하지만, 상위 단계는 다른 의사소통 과제를 갖는다.

| 상황 | Lv.1: 짧게 말하기 | Lv.2: 문답 | Lv.3: 이유·조건 | Lv.4: 조율·문제 해결 |
|---|---|---|---|---|
| 스몰토크 | 여행자와 인사 | 주말·취미 | 공통 관심사와 경험 | 의견 차이·개인적 질문·마무리 |
| 클럽·바 | 인사·요청 | 음악 취향 문답 | 감상·활동 제안 | 거절·주문 착오 조율 |
| 카페 | 한 잔 주문 | 메뉴 질문 | 취향·시간 조건 | 주문 착오·대안 |
| 식당 | 자리·첫 주문 | 재료·먹는 방법 | 취향·제공 순서 | 누락·계산 문제 |
| 호텔 | 체크인 | 시설·이용 시간 | 일정에 맞춘 부탁 | 객실 불편·예약 착오 |
| 길 찾기·교통 | 가까운 목적지 | 노선·환승 | 시간·짐·날씨 조건 | 잘못 탄 열차·운행 중단 |
| 쇼핑 | 고르고 구매 | 색·크기 비교 | 용도·예산 비교 | 교환·상품 문제 |
| 친구와 약속 | 함께하자고 제안 | 시간·장소 정하기 | 서로의 취향 반영 | 지각·일정 변경 |

앱의 4단계는 자체 연습 단계이며 공인 숙달 등급이나 CEFR/JLPT 판정이 아니다. 기존 starter ID와 학습 이력은 유지한다. 학습 완료는 발음·회화 숙달 판정이 아니다.

## 화면과 데이터

- 카드의 첫 예문 대신 해당 수업의 말하기 목표를 표시한다. 새 수업(10문장), 복습, 관리자 추가 표현(1문장)을 구분한다.
- 수업 안에서 장면, 목표, 현재 발화 의도를 확인하고 이전·다음으로 이동한다. 긴 문장에서도 이동 버튼을 하단에 유지한다.
- AI 회화 프롬프트도 같은 상황·레벨 계획을 사용한다. 계획은 발판이며 기존 대화 흐름과 사용자의 답변을 덮어쓰지 않는다.
- 관리자 게시 항목은 검수된 한 표현만 제공한다. 무관한 공통 문장으로 열 개를 채우지 않고 완료 기록·안내에도 실제 한 문장을 표시한다.
- `v2-scene-plans.json`: 한국어 목표·장면·발화 의도·원문.
- `v2-scene-phrases.json`: 한국어/일본어/일본어 한글 발음/태국어/태국어 한글 발음/영어/영어 한글 발음/스페인어/스페인어 한글 발음 순의 9열.
- `v2-scene-lessons.ts`: 계획과 번역, 기존 클럽·바 수업 결합. `v2-lesson-data.ts` 공통 채움 문장은 삭제했다.

## 콘텐츠 검토

LiteLLM을 통한 번역 초안을 원문과 대조하며 교정했다. 대표 수정: 메뉴판 세 개→음식 세 개 오역, 두 침대→더블룸 혼동, 사진을 찍다의 직역, 주문 확인을 질문으로 바꾼 문장, 일본어 칸의 한국어, 태국어 철자와 외국 문자 혼입, 스페인어 악센트·문법, 한글 발음 칸의 원어 문자 혼입.

자동 검사는 모든 언어의 전체 원어 중복, 허용 문자, 한글 발음 문자, 원문 순서·뜻 보존, 안전한 학습 표현 형식, 수업당 10문장, 단계별 다른 목표를 검증한다. 영어의 같은 상황·다른 레벨 문장에 대한 문자열 유사도 보조 점검에서도 0.82 초과 쌍은 없었다. 이는 의미 중복이나 번역 정확성을 보장하는 지표는 아니다.

외부 원어민의 전문 감수나 1,280문장 전체 음성 청음은 수행하지 않았다. 한글 표기는 근사 발음 도움이며 성조·강세를 온전히 표현하지 못한다. 앱의 기존 음성 병행 안내를 유지한다.

## 검증

- 단위 테스트 77개 통과: 전체 128개 수업 데이터, AI 미션 연결, 사용자 격리·진도·기존 기능 포함.
- E2E: 일본어 32개 수업의 320문장 실제 표시, 카드 목표·장면·발화 의도, 이전·다음, 가로 넘침, 스크롤 전 이동 버튼, 닫기 후 진도 보존.
- E2E: 관리자 게시 표현 1문장 표시·완료·실제 기록 1 확인.
- 기존 가입·로그인·4언어·음성 요청·양방향 번역·대화·Codex/Claude 연결 흐름·관리자 검수/회수·반응형 회귀 시나리오 통과. E2E의 외부 공급자는 fixture이며 실제 공급자 회화 품질 시험과 구분한다.
- ESLint 오류 0, 기존 미사용 변수 경고 4개.
- Next.js 운영 빌드·TypeScript 검사·47개 경로 생성 통과. 기존 middleware→proxy 전환 안내는 이번 범위 밖이다.
- 운영 배포 전 PR 검토·명시적 머지 승인 필요. 작업 브랜치의 검증이며 운영 반영 완료를 뜻하지 않는다.
