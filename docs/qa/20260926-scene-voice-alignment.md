## 변경

- Google 이미지/영상과 Higgsfield에 기획 의도, 장면 대본, 해당 장면의 편집 자막을 함께 전달한다. 화면 구상이 대본 의미와 충돌하면 대본·자막을 우선하고, 추상적 내용은 구체적인 시각적 비유를 요청한다.
- 시나리오 LLM이 지원 음성 목록에서 목소리와 추천 이유를 반환한다. 유효한 추천은 첫 편집 시 자동 선택한다. 추천이 없는 기존 프로젝트는 기본 추천임을 표시하며, 사용자가 선택한 목소리와 내레이션 없음 설정은 보존한다.
- 편집기에 추천 목소리와 이유, 선택 버튼을 제공한다. 대본이 바뀌면 기존 LLM 추천을 그대로 재사용하지 않는다.
- 완성된 장면별로 대본·자막에 맞춰 다시 만들기를 제공한다. 사용료 검수 확인이 필요하며 선택 장면만 재생성한다. 진행 중이거나 결과가 불확실한 미완료 장면은 이 경로로 새 결제를 시작할 수 없다. 기존 재시도는 동일한 요청 식별과 영수증을 유지한다.
- 대본 수정 시 AI 장면만 무효화하며 사용자 업로드는 보존한다. 자막 수정만으로 유료 생성을 자동 실행하지 않는다.
