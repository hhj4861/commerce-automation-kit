## 실제 검증 결과

- `npm ci --prefix . --workspaces=false`: 잠금 파일 변경 없이 설치 성공. 처음의 단순 `npm ci`는 모노레포 루트 workspace 잠금 파일을 선택해 실패했으므로, 기존 CI와 동일한 앱 전용 설치 명령을 사용했다.
- `npm test`: **25/25 통과**. 학습 시간 변경 시 레벨·피드백·정답 기록·회화 revision 유지와 재진단 격리 테스트 추가.
- `npm run build`: **성공**, Next.js 운영 빌드 및 TypeScript 검사 통과.
- 변경한 React·라우트·학습 로직 ESLint: **통과**, `git diff --check` 통과.
- 확장한 `npm run test:language-flow`: **종료 코드 0**. 격리한 Next 서버·실제 인증/API·파일 저장소·Chromium을 사용하고, 외부 Dify 및 음성 제공업체만 합성 응답으로 대체했다. 운영 키나 학생 데이터는 테스트에 복사하지 않았다.
- 한국어·태국어·일본어: 로그인 → 언어 선택 → 6문제 → 결과 → 회화 2회 → 난이도 확정 → 학습 계획 → 새로고침 저장 유지 통과.
- 문제 답/회화 내용/보내기 전 입력 복구, 이전 문제 수정, 결과 복구, 재진단 중단, 피드백 후 대화 재개, 학습 시간 변경, 주제 전환·복귀 통과.
- 저장/API 503 응답 후 입력 유지·재시도, 브라우저 저장소 쓰기 제한 시 입력 유지·안내, 새 대화 취소/확인 통과.
- Chromium 가상 마이크: 합성 권한 거부 → 텍스트 사용 가능 → 재시도 → MediaRecorder → 실제 앱 음성 인식 API → 합성 전사문 확인 통과. 새로고침 후 음성 재생 API 200과 자동 듣기 설정 유지 확인.
- 긴 AI 답변 첫 부분 표시, `**강조**` 표시, HTML 문자열 비실행, 320/390/768/1280px 밝은/다크 모드 가로 넘침 없음. 주요 보내기 버튼 글자 대비 4.5:1 이상.
- 첫 퀴즈 응답 멱등성, 재진단 언어 격리, 오래된 revision 409, 다른 계정/학생 범위 거부, Origin 403, 비인증 401, 진단 과다 요청 429 유지.
- 마지막 실행에서 브라우저 pageerror 및 hydration 오류 **0건**. 테스트 서버·브라우저·임시 데이터는 종료 및 정리됨.

초기 확장 검사에서는 스크린샷 도구의 caret 숨김이 hydration 전에 적용되는 충돌과 Next route announcer를 포함한 중복 오류 선택자를 발견했다. 스크린샷 caret 설정·대상 선택자를 수정했다. 포커스 검사는 requestAnimationFrame이 끝나기 전에 단언하던 것을 실제 포커스 전환 완료를 기다리도록 변경했다. 가상 마이크 재시도에서 한 번 시작 대기가 실패했으나 분리 검증 및 최종 통합 실행에서는 정상 녹음·전사까지 확인했다.

## 검증의 한계와 적용

실제 휴대폰 Safari/Android 키보드, 물리 마이크·스피커 청음, 화면 읽기 도구, 실제 LLM의 문법·발음 정확도는 이번 자동 테스트로 보장하지 않는다. 새 변경에서 외부 모델은 합성 응답을 사용했으며 이전 PR #50의 운영 실제 Dify 테스트와 혼동하지 않는다. 이번 저장소 변경은 운영 연결 키나 Dify 설정을 바꾸지 않는다.
