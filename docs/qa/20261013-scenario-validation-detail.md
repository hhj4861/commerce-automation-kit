# 대본 형식 보완 진단

- 목표: 운영 대본 형식 실패에서 LLM이 어느 필드를 고쳐야 하는지 알 수 있게 한다.
- 담당/범위: Codex 단독, studio-scenario·webtoon-plan·validateScenes의 오류 문맥, 관련 검사.
- 기준: main e154e577. 운영 b14a000의 실요청은 FORMAT_INVALID로 종료, 원본 미보존으로 당시 필드는 미확정.
- 변경: 검증기가 만든 필드/규칙만 1회 보완에 전달. 웹툰 레이어·장면 인덱스와 목표 길이를 구분. 스타일과 모순되는 고정 24초 이미지 JSON 예시 제거. 검증 기준/품질 검토/과금/재시도 한도 유지.
- 완료 기준: 유효하지 않은 중첩 웹툰 입력→정확한 보완 힌트→수정본 검토, 최종 반복 실패/공유 1회 예산 검사. 본 수정만으로 실생성 성공을 주장하지 않는다.
- 현재: 구현 및 관련 64개 검사 통과. 웹툰 스타일/기하 제한/조사→대본→검토 추가 3개 검사 통과. 공개 오류에도 고정 항목명만 남기며 원본 입력·자격은 출력하지 않는다. 운영 자동배포 허용 브랜치 누락은 별도 설정 복구 중.

- `node --test` 실행: studio-scenario-repair / scenario-review-feedback / explanation-depth / studio-scenario-account / llm-accounts — 64 pass, 0 fail, 0 skip.
