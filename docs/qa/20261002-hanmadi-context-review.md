## 변경한 판단 흐름

1. JEV가 뜻·발음·관찰 근거·상황·신규성을 평가한다. 기존 confidence 0.85 / 선택 확률 0.90 기준은 변경하지 않았다.
2. 확실한 JEV fail 또는 정확 중복은 그대로 제외한다. 해당 후보를 보조 모델이 되살릴 수 없다.
3. 불확실한 후보만 영상당 한 번의 LLM 교차 검수에 보낸다. 이전의 언어 세 항목에 상황·기존 자료 중복을 추가하고, JEV에 제공한 것과 같은 상황 설명·레벨 지원·선별 비교 자료를 전달한다. 최대 6개 후보, 비교 자료 최대 24개 및 기존 9KB 선별 범위를 유지한다.
4. 모델은 표현 자체의 언어를 별도로 식별한다. 목표 언어와 다르거나 불확실하면 그 행만 검토 대기로 남기고 원래 모델 답을 보존한다. 다른 정상 행까지 영향을 주지 않는다. 명시적인 언어 식별 값도 모델 출력이므로 그 자체가 언어 정답의 보장은 아니다.
5. 교차 검수 다섯 항목이 모두 pass일 때만 후보가 품질 검사를 통과한다. 뜻·발음·근거 오류는 제외한다. 상황·의미 중복에 대한 보조 검수의 부정 판단은 직접 확인할 수 있도록 검토 대기에 남긴다. JEV의 확실한 부정 판단은 여전히 제외한다.
6. 품질 통과 후보 사이에는 기존 JEV 의미 중복 검사를 수행한다. 최종 채택한 앞 후보만 비교 기준이며, 제외·검토 대기 후보는 중복 기준으로 사용하지 않는다. 마지막 중복 판정이 불확실하면 검토 대기로 남긴다.
7. 저장은 계속 초안이며 관리자 검수·게시 전 앱 학습이나 파인튜닝에 넣지 않는다. 기존 저장 자료를 자동 재평가하거나 게시하지 않는다.

원 JEV `checks`·confidence는 변경하지 않는다. 별도의 `contextReview`에 모델, 식별 언어, 항목별 이유, 실제 중복 참조, 비교 범위와 입력 해시를 기록한다. 화면에는 저장 당시 검수 기록, 비교 자료 수/전체 수, 중복 대상 문장을 표시한다. LLM 검수를 JEV의 높은 확신으로 바꾸어 표시하지 않는다. v7의 저장된 `languageReview` 표시도 유지한다.

## 호출·실패·캐시

- `HANMADI_VIDEO_REVIEW_MODEL`이 있으면 사용하고, 없으면 기존 `LITELLM_MODEL`을 사용한다. 기존 Hanmadi gateway 키만 사용하며 개인 키 fallback은 없다. JEV 키는 별도 유지한다.
- 보조 검수는 영상당 최대 1회, 15초(응답 본문 포함), 자동 재시도 0, 출력 최대 3,000토큰/12,000자다. 다섯 항목의 근거와 언어 식별을 담도록 v7의 1,800토큰/8,000자에서 확대했다. 영상 선택 최대 10개, 분석 동시 3개는 유지한다.
- 누락·중복·범위 밖 인덱스·추가 필드·잘못된 판정값·잘못된 중복 참조 인덱스 등 구조 오류는 응답 전체를 거부하고 검토 대기로 둔다. 언어의 의미상 불일치는 해당 행만 격리한다.
- 기존 JEV 두 단계와 합쳐 영상당 최대 3회 평가 요청이다. 모든 단계의 실제 요청은 합성 실호출 도구의 같은 요청 상한에 포함한다.
- rubric을 `hanmadi-video-jev-v8`로 변경하여 이전 결과 캐시와 구분한다. 기존 reviewModel 기반 캐시 구분도 유지한다.
- 신규성은 전달된 선별 자료 안에서만 비교한다. 전체 자료의 의미 중복을 전수 확인했다고 주장하지 않는다. 관찰 근거 검사도 영상 원본의 독립 검증이 아니라 분석 기록의 일관성 검사다.

## 실제 평가에서 발견하고 수정한 문제

첫 실험은 정상 표현 중 카페인을 뺄 수 있는지 묻는 표현을 기존 디카페인 희망 표현과 중복으로 제외했다. 또한 JEV를 생략한 보조 검수 단독 시험에서 스페인어 상황에 영어 포크 요청을 통과시켰다. 전체 파이프라인에서는 해당 영어 표현을 JEV가 제외했지만, 보조 검수의 약점으로 기록했다.

이에 언어 식별 및 불일치 차단을 추가하고, 보조 모델의 상황·중복 이견은 제외 대신 검토 대기로 남겼다. 첫 실험 원본과 기존 라벨을 보존했다. 최종 재평가에서 디카페인 표현은 모델이 pass를 반환했다. 따라서 이 한 사례의 재평가 결과만으로 새 이견 보류 로직이 결과 향상의 단독 원인이라고 주장하지 않는다. 해당 로직의 효과는 동일 입력에 대한 회귀 검증으로 별도 확인했다.

최종 남은 보류:

- 일본어 냅킨 요청: 언어·상황 교차 검수는 통과했지만 마지막 JEV 배치 중복 검사에서 distinct 확신이 기준에 못 미쳤다.
- 영어 수건 요청 및 같은 요청의 바꿔 말하기: 보조 모델 응답에 허용되지 않은 `text` 필드가 추가되어 두 행 모두 구조 검증에서 보류했다. 연결 오류가 아닌 응답 계약 오류이며 자동 재시도하지 않았다.
- 영어 호텔 상황의 식당 예약 사례는 호텔 컨시어지 업무와 겹칠 수 있는 인접 상황 경계 사례다. 고정 라벨은 그대로 유지하고 명백한 언어 오류와 구분한다.

추가 보조 검수 단독 시험 12개에서 서로 다른 언어 2개는 최종 코드가 언어 불일치로 보류했다. 오역·관찰 실패·주입 지시·상황 불일치도 부정 판정을 받았다. 두 배치의 바꿔 말하기는 기존 자료가 아니라 같은 배치 중복이므로 이 단계만으로 제외하지 않는다. 이를 전체 흐름 오채택으로 계산하지 않고, 마지막 JEV 중복 검사의 별도 책임으로 기록한다.
