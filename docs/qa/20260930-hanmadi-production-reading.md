## 실제 운영 API 재검증

별도 일반 QA 계정에서 자동 학습을 끄고 `얼음 없이 커피 한 잔 주세요.`를 4개 언어로 번역했다. 인증값은 메모리에만 두었고 종료 시 로그아웃했다. 생성 계정은 남아 있으며 표현은 모두 `saved:false`, 저장 표현 목록은 비어 있었다.

| 언어 | 번역 결과 | 번역 소요 | 음성 HTTP / 바이트 / 전체 시간 |
|---|---|---|---|
| 일본어 | 氷抜きでコーヒーを一杯ください。 | 18996ms | 200 / 36824 / 2895ms |
| 태국어 | ขอกาแฟหนึ่งแก้ว ไม่ใส่น้ำแข็ง | 2245ms | 200 / 39332 / 4044ms |
| 영어 | Please give me a cup of coffee without ice. | 3928ms | 200 / 41839 / 3207ms |
| 스페인어 | Un café sin hielo, por favor. | 2201ms | 200 / 26793 / 2294ms |

태국어 원문은 커피 철자와 얼음 제외 조건을 유지했고 불필요한 온도를 추가하지 않았다. 일본어 번역 1회는 약 19초로 느렸으며 원인을 확정하지 않았다. 음성 첫 생성의 제공자 지연은 여전히 남아 있다.

## 추가 발견과 후속 변경

스페인어 원문 번역은 적절했지만 한글 발음이 `운 까페 씨ㄴ 이에로, 뽀ㄹ 바호ㄹ.`로 생성됐다. 기존 검사는 Hangul 문자이면 분리 자모도 허용했다.

- NFC 정규화 후 완성형 한글 음절만 발음 문자로 허용한다. 분리된 ㄴ/ㄹ/모음 또는 불완전한 조합 자모를 거부한다. 정상 NFD 한글은 NFC로 조합 가능하므로 허용한다.
- 번역 지시에 완성형 음절 사용과 스페인어 `sin hielo, por favor`의 발음 예시를 추가했다.
- 기존 1회 재생성 경로로 처리하며 계속 잘못되면 결과/학습 자료를 반환하지 않는다. 동일 검사가 AI 회화에도 적용된다.
- 실제 관측 문자열의 재생성/지속 실패 차단, 회화의 분리 자모 거부, 정상 NFD 허용 회귀 테스트를 추가했다.
- 이 후속 변경은 PR #92 배포에 포함되지 않았다. 별도 PR의 승인·머지·배포가 필요하다. 완성형 한글 검사만으로 모든 발음 정확성을 보장하지 않는다.
- 후속 변경 검증: `npm test` 102개 통과, lint 오류 없음(기존 경고 4개), `git diff --check` 통과. 전체 E2E는 PR CI에서 별도로 실행한다.
