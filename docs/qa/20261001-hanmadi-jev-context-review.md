## 질문별 입력 분리 실험

[JEV 공식 한계 문서](https://docs.typesafe.ai/model-jaggedness/jev-1.13)의 무관한 맥락 축소 권고를 바탕으로 다음 가설을 시험했다. 의미·독음·근거·상황 질문에는 해당 필드만 전달하고, 기존 자료 목록은 중복 질문에만 전달하면 판단이 명확해질 수 있다는 가설이다. 원래 기준 문구와 confidence ≥ 0.85 / 선택 확률 ≥ 0.90 조건은 유지했다.

기존 24개 고정 자료의 배치 1·3, 총 12개를 사용했다. 정상 4개, 부적합 8개이며 라벨·입력·순서를 바꾸지 않았다. 평가 자료는 assistant 작성 합성 일본어 카페 사례이며 독립 전문가 검증이나 새로운 블라인드 표본은 아니다.

| 지표 | 같은 12개의 기존 v6 응답 | 입력 분리 후 실호출 |
|---|---:|---:|
| 자동 채택 | 0 | 0 |
| 검토 대기 | 4 | 4 |
| 제외 | 8 | 8 |
| 정상 표현 잘못 제외 | 0 | 0 |
| 부적합 표현 자동 채택 | 0 | 0 |
| 입력 토큰 | 21,510 | 36,781 |

정상 4개의 근거 판단 confidence는 기존 0.77~0.82에서 0.99~1.00으로 높아졌다. 그러나 발음·상황·중복의 불확실성은 남았고 최종 처리 결과는 개선되지 않았다. 기존 자료를 각 중복 질문 안에 반복하면서 전송량도 증가했다. **이 변경은 채택하지 않았다.** 본인 수정 두 파일만 원복했고, 재현용 패치는 산출물 폴더에 보존했다.

실험 변경 상태에서 앱 회귀 170개, 변경 파일 ESLint, `git diff --check`가 통과했다. 이는 실행 보호와 요청 구성 회귀 검증이며 모델 품질 목표 통과를 뜻하지 않는다.

## 2차 의미 중복 판정의 독립 실호출

1차 품질 결과가 모두 검토 대기여서 기존 실험은 2차에 도달하지 못했다. 이를 분리해, 정상 문장과 그 바꿔 말하기를 포함한 합성 표현 6개·비교 15쌍을 앱의 실제 2차 질문 구성과 처리 코드로 평가했다.

**1차 품질 응답은 시험용 고정 pass다. 실제 JEV 품질 통과가 아니다.** 실제 모델 호출은 2차 한 번뿐이며, 원문 영상·브라우저·저장·게시를 거친 전체 흐름 검증도 아니다. 요청에 기대 라벨은 넣지 않았다. 두 바꿔 말하기 쌍을 중복, 나머지 13쌍을 다른 학습 내용으로 사전에 구분했다.

- 원시 분류 15/15가 이 합성 기대와 일치했다.
- 컵 요청의 바꿔 말하기와 영수증 요청의 공손 표현은 각각 duplicate confidence 0.98, probability 0.99였다.
- 최종 2차 처리: 중복 제외 2개, 중복 검사 통과 3개, 불확실 검토 1개.
- 냅킨 요청은 컵 요청과의 비교 confidence 0.77, 빨대 요청과의 비교 confidence 0.06 때문에 검토로 남았다. ‘원시 분류 일치’와 ‘자동 처리 가능’을 구분한다.
- 이미 중복 제외된 후보를 나중 후보의 기준으로 사용하지 않는 `used=false` 처리도 실제 응답에서 확인했다.

결과 파일의 `accepted` 3은 **고정 품질 응답을 전제로 2차만 통과한 값**이다. 정상 표현 3개가 실제 품질 심사를 통과해 앱에 추가됐다는 뜻이 아니다. 저장·게시·파인튜닝은 실행하지 않았다.
