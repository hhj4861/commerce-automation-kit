# 태국어 남성 화자 기본값 — 2026-10-01

사용자 요청: 태국어 문장을 우선 남자가 말하는 어체로 제공한다.

## 변경

- 기본 교재 8개 상황 × 4개 레벨 × 10문장, 총 320문장의 태국어 원문과 한글 발음을 남성형으로 변경. `ค่ะ/คะ → ครับ`, 1인칭 `ฉัน → ผม`, 해당 발음 `카 → 캅`, `찬 → 폼`.
- 런타임에서 임의 문장을 일괄 치환하지 않고 검토한 교재 데이터를 수정했다. 요금 `ค่า`의 ‘카’, 층 `ชั้น`의 ‘찬’은 유지. `friends:2` 한 문장의 중복된 발음도 해당 원문에 맞게 정리.
- 한국어 뜻·일본어·영어·스페인어 열, 상황/레벨/과정 ID/목표는 HEAD와 비교해 동일함을 확인.
- 한국어→태국어 번역, AI 대화 상대, 한국어로 입력한 내 말의 태국어 표현에 남성 화자 기본 지침 적용. 보통 1인칭은 ผม, 공손한 질문·서술은 ครับ. 단어마다 말끝을 붙이지 않으며 짧은 구에는 강제하지 않음.
- 여성형 말끝이나 문말 ครับ의 잘못된 발음이 검출되면 기존의 동일 모델 1회 교정 경로 사용. 2회 실패하면 올바르지 않은 표현을 반환·저장하지 않음. 제한된 형식 검사이며 모든 태국어 의미·발음을 판정하는 기능은 아님.
- 태국어→한국어는 상대가 실제로 말한 원문·발음을 유지. 여성 화자 입력도 정상 번역하며 그 원문의 연습용 발췌도 임의로 남성형으로 바꾸지 않음.
- 학습 창 안내를 남성 화자 기준으로 갱신. 계정 성별을 추정·수집하지 않음. 음성 합성 목소리 설정은 이번 문체 변경과 별개.
- 기존 개인 저장 표현·관리자 자료는 일괄 재작성하지 않음. 새로 생성되는 내 말 및 기본 교재에 적용.

## 검증

- 한마디 단위 테스트 126개 통과, 변경 파일 ESLint 및 TypeScript, production build 통과.
- 전체 v2 브라우저 E2E 재실행 exit 0. 4개 언어 1,280문장 순회·화면 크기별 배치·번역·AI 대화·저장/삭제/opt-out·계정 연결·관리자/학습 파이프라인 통과. 테스트 서버 종료와 격리 데이터 삭제 확인.
- 각 태국어 교재에 ครับ과 대응 발음 확인, 요금/층수 단어 보존 회귀 포함.
- 한국어→태국어 여성형 출력의 재생성, 개인 선택 모델 유지, 역방향 여성형 원문 및 따옴표로 인용한 여성 화자 보존, 실패 표현 차단, คะน้า 같은 일반 단어의 오탐 방지 검증.
- 다른 언어 교재와 과정 메타데이터 불변을 소스 비교로 확인.
- 기존 E2E의 고정 500ms 지연은 느린 iCloud 파일 I/O에서 삭제 요청보다 먼저 끝나 검증이 실패했다. fixture 응답을 삭제·저장 해제 완료까지 명시적으로 보류하도록 바꿔 실제 검증 순서를 고정했다. 제품의 저장 차단 로직은 변경하지 않았다.
- 실 API를 대체한 fixture 공급자의 격리 브라우저 E2E로 UI 노출·번역·대화·저장 흐름 검증. 실제 Gemini/Codex/Claude의 태국어 생성 품질 감수나 운영 배포 결과와 구분.
- 처음 저장소 루트에서 실행한 npm test는 다른 패키지의 미설치 vitest/tsx로 실패했다. 앱 범위에서 다시 수행한 검증을 위 결과로 기록하며 저장소 전체 통과를 주장하지 않는다.
