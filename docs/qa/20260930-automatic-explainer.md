# 자동제작: 추천부터 근거·대본·영상까지

사용자가 승인한 타이베이 101 설명 영상 제작 과정을 자동제작에 연결하는 변경이다. 기준은 main ad7b8dc, 구현은 feat/automatic-explainer-pipeline. 현재 기록은 격리 로컬 검증이며 운영 Pages·credential broker·구독 LLM 워커·미디어 워커에는 아직 배포하지 않았다.

## 사용자 흐름

카테고리·제작 방식·길이 선택 → 검색 기반 주제 추천 → 주제 선택 → 해당 주제 자료 검색 → 대본 작성 → 사람의 대본 승인 → TTS·장면 생성 → 자막·영상 조립 → 최종 검수. 업로드는 별도 검수 동작으로 유지한다. 사용자는 설명 애니메이션과 Higgsfield 시네마틱 제작 중 하나를 선택하고 분위기·연출을 직접 지정할 수 있다.

새 요청은 explainer-v1 설정을 저장한다. Yooni·숏폼 1.15배속·롱폼 1배속·중앙 자막이 기본이며 선택을 바꿀 수 있다. 기존 프로젝트/저장된 추천에는 새 프로필을 강제로 넣지 않는다. 선택한 제작 방식과 계정 소유자는 서버 보관 추천에서 가져온다.

자료 검색은 구독 LLM 실행기의 내장 웹 검색을 사용한다. 검색 실행 증거가 없거나 출처·사실 참조 형식이 맞지 않으면 중단한다. 공식 원문 우선·확인되지 않은 인과/숫자 제외를 지시하고 sources/facts/limitations를 대본과 함께 보관한다. 이는 모든 문장의 사실성을 자동 증명하는 시스템이 아니며 대본 승인 화면에서 출처와 적용 한계를 검토해야 한다. 임의 URL을 서버에서 다운로드하는 기능은 추가하지 않았다.

## 영상·음성

애니메이션은 검증된 제한형 데이터만 SVG로 렌더한다. LLM이 생성한 JS/SVG/HTML을 실행하지 않는다. 개체 도식에 건물·바람·댐퍼·행성·물·에너지를 추가하고 상대운동, 건물 단면의 흐름, 궤도 도해를 지원한다. 움직임과 비율은 설명용이며 실제 시뮬레이션이 아님을 표시한다. 임의 주제의 맞춤 3D 장면을 무제한 생성하는 기능은 아니다.

새 자동제작은 음성을 먼저 생성·측정한다. 선택 배속을 음높이 유지 atempo로 적용하고 속도를 캐시 식별에 포함한다. 애니메이션과 자동 타임라인은 발화 길이+약 0.3초로 맞춰 긴 빈 시간을 줄인다. 음성 원본 캐시와 완성 장면을 재사용한다. 이미 편집한 타임라인은 자동으로 덮어쓰지 않는다. 자막은 기존 문장·단어 분할과 길이 비례 시간을 사용하며 단어별 음성 강제 정렬은 아니다.

시네마틱 선택은 Higgsfield로 명시적으로 분기한다. 기존 공식 CLI·Cloudflare 인증·크레딧 견적·영수증/중복 방지 경로를 재사용하고 인증 실패 시 Google로 몰래 전환하지 않는다. 외부 장면 품질·인물 일관성은 모델 결과에 따라 달라지며 최종 검수를 유지한다.

## 검증

- Shopshorts 전체 Node 테스트 300/300 통과. 최종 UI 복원 수정 뒤 관련 14/14 재검증 통과.
- 신규 테스트는 검색→시나리오 순서, 출처 보존·검색 미실행 거부, 설정 검증, 제한형 도해 렌더·escaping, 실제 배속 MP3/MP4, 재시도 시 TTS 재사용, Higgsfield 강제 분기, 단계 표시를 확인한다.
- Pages API와 credential broker의 Cloudflare 번들 성공. cloudflare:workers는 런타임 모듈로 external 처리했다.
- 실제 Chrome: 추천→자료 확인→대본 승인→워커의 음성·장면 생성→자동 렌더→1080×1920 MP4 재생 성공. 재생 위치가 증가하고 새로고침 후 완성 작업이 복원됐다. 콘솔 pageerror 없음. 모바일 가로 넘침 없음.
- 브라우저 fixture의 검색·LLM·TTS 제공자 응답은 테스트 데이터/사인파이며 실제 유료 구독 호출을 검증했다는 뜻이 아니다. 렌더러·API·CAS·작업 큐·브라우저는 실제 코드다. 실제 생성 예시는 별도 건축학 영상 결과물이다.
- 초기 전체 회귀에서 발견한 capabilities의 잘못된 job 참조를 수정했다. 테스트 서버의 미디어 저장소 인자 형식도 실제 API에 맞춰 수정한 뒤 최종 재생까지 확인했다.

재현: npm test -w @cak/app-shopshorts. 브라우저 fixture: node apps/shopshorts/test/explainer-browser.mjs → http://127.0.0.1:5231/studio/dashboard?mode=auto. 외부 제공사 호출은 하지 않는다.

## 배포 경계

사용자 PR 머지 승인 후 Pages, credential broker(단계 노출·시간 제한), 계정 LLM 워커(검색·대본), 제작 워커(배속·도해)를 같은 리비전으로 반영해야 한다. Pages만 배포하면 완료가 아니다. 이 시점 origin/deploy/shopshorts 브랜치는 존재하지 않아 main 기준 PR로 준비한다. 공용 GitOps 배포 브랜치 활성화 자체를 완료했다고 주장하지 않는다. 운영에서 새 요청의 단계 진행과 두 제작 분기를 재확인해야 한다.

## 실제 제작에서 얻은 추가 보완

시네마틱 건축 영상 제작 중 이전 컷의 기계 소재가 다음 요청에서도 반복되는 출력이 관찰됐다. 새 explainer-v1은 공통 화풍을 유지하되 이전 장면의 전체 묘사를 제공사 입력에서 제외하고 현재 장면의 대상·동작을 명시한다. 이는 출력 일관성을 보장하는 수정은 아니며 새 프롬프트의 유료 재생성은 하지 않았다. 프롬프트 회귀로 이전 컷 묘사 제외·현재 지시·공통 화풍 유지를 확인한다. 선택 배속에 맞는 대본 분량 안내도 보완했으며 분량은 초안 가이드, 최종 길이는 실제 음성 기준이다.
