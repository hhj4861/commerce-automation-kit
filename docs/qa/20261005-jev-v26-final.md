## 최초 오류와 별도 진단

`eiffel-3`의 bridge는 538ms에 exit 1 / `jev_unavailable`로 끝났고 서비스가 `verification_failed`로 보류했다. 게이트웨이는 성공·과금을 기록했으며 해당 오류 테이블에는 행이 없었다. 원래 bridge가 SDK 세부 오류를 감추므로 원인은 미확인이다. 5초 timeout보다 짧았다는 사실만으로 원인을 단정하지 않는다.

이 새 증거를 남긴 뒤 같은 SDK·키·모델·timeout에 비밀을 제외한 오류 코드 관찰만 추가한 별도 계획으로 1회 진단했다. 진단 파일의 `eiffel-1`은 원본 `eiffel-3`에 해당한다. JEV는 openingVisual의 근거 부족을 confidence .93 / 선택 확률 .95로 판정했고, 언어모델 재검수 없이 보류했다. 자동 재시도 0; 최초 실패를 교체하거나 의미 판정 성공에 포함하지 않았다. 간헐적 bridge 실패 원인은 여전히 조사 과제다.
