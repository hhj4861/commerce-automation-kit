## 발견한 화면 오류와 변경

운영에서 완료된 프로젝트를 다시 열면 대본 검수 전인데도 3단계 이미지·영상 화면으로 이동했다. 그 결과 완료 안내와 수정할 대본이 바로 보이지 않았다.

`resumeStep`을 도입해 미검수 대본은 2단계로 복원한다. 승인 후에는 준비된 미디어에 따라 3/4단계, 렌더·업로드 결과는 5단계로 복원한다. 진행 중·실패한 작업은 해당 작업 단계로 복원한다. 생성·발행 사람 승인 조건은 그대로 유지한다.

로컬 `127.0.0.1:5199`의 격리된 메모리 저장소와 실제 `studioApi`/정적 UI로 검증했다. Chrome에서 URL 직접 진입 → 2단계 완료 안내·대본 표시 → 3단계 이동 → 새로고침 → 2단계 복원을 확인했다. 이 로컬 검증의 계정 표시와 프로젝트 데이터는 테스트 대역이며, 실제 Google 로그인·LLM 호출 증거는 위 운영 E2E와 구분한다.
