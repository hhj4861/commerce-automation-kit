- 서버의 변경 없는 Node bridge·공통 SDK로 실제 Jev를 호출했다. 서버 환경의 discovery 전용 키만 사용하고 키 원문을 읽어 출력하거나 외부로 복사하지 않았다. 실제 응답을 머지된 `Discovery` 연구·초안 완료 흐름에 재생해 격리 SQLite에 저장했다. 운영 HTTP → 저장소 전체 E2E는 아니다.

## 남은 판단

현재 정상 수락의 필수 게이트로 JEV를 활성화할 근거는 부족하다. 기존 LLM 검수 경로와 같은 사례·증거·예산으로 비교하고, 정상 통과율·잘못된 통과율·과보류·총비용·전체 지연을 측정해야 한다. JEV를 명백한 모순/오류 선별 보조로 한정할지, 일부 판단에서 제외할지도 이 비교로 결정한다. 새 fallback이나 자동 재시도는 구현하지 않았다.
