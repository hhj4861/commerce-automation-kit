# Hanmadi 운영 E2E — 음성·스터디·AI 대화·번역

- 검증일: 2026-10-01 (KST)
- 운영: https://hanmadi-lake.vercel.app/study
- `/api/deployment` 확인 리비전: `d09ce02d03f9087ca00f53d5fff8d6a477bda9c2`
- 결론: 기능 경로와 음성 캐시는 작동한다. **첫 음성 대기, 태국어 내 말 변환의 의미 오류, 일본어 학습 발음 표기 오류, AI 대화 흐름은 보완이 필요하다.** 전체 품질 통과로 판정하지 않는다.
- 이 작업은 검증과 보고서 작성이다. 앱 코드 변경·머지·운영 배포는 하지 않았다.

## 방법과 범위

실제 운영 서비스에 Chrome headless/Playwright로 접속했다. API·AI·TTS 응답을 mock하지 않았다. 일반 QA 계정을 사용하고 기본 Gemini 경로를 확인했다. 사용자 개인 OAuth 연결은 건드리지 않았다.

음성은 DOM 클릭 시각에서 HTMLMediaElement의 `playing` 이벤트까지 측정하고 `currentTime > 0.05` 진행을 확인했다. 재생 함수를 원래대로 호출하면서 이벤트만 관찰했다. 응답 다운로드 시간이나 자동화 명령 소요 시간을 음성 시작 시간으로 대체하지 않았다. 실제 스피커 청음, 모바일 실기기, Safari, 마이크 녹음/STT는 이번 범위 밖이다.

주 검증은 390×844 화면에서 수행했고, 보충 검증은 320/390/768/1440px의 AI 대화 도구 모음과 페이지 가로 넘침을 확인했다. 네트워크 속도를 인위적으로 제한하지 않았다. 각 조합의 소수 실측값이며 평균/p95나 모바일 통신망 SLA가 아니다. 첫 재생은 해당 브라우저에서 처음 듣는 문장이며 공급자 내부 캐시의 cold 상태를 뜻하지 않는다.

## 음성 실측

단위: 초. 재생 준비 버튼을 클릭한 뒤 실제 브라우저 재생 시작까지.

| 언어 | 스터디 첫 문장 | 다음 문장 즉시 듣기 | 번역 첫 듣기 | AI 답변 첫 듣기 | 같은 문장 반복 |
|---|---:|---:|---:|---:|---:|
| 일본어 | 2.533 | 1.514 | 2.581 | 3.955 | 0.017–0.018 |
| 태국어 | 2.101 | 1.569 | 2.963 | 4.355 | 0.017–0.018 |
| 영어 | 2.102 | 2.207 | 2.284 | 3.926 | 0.017–0.018 |
| 스페인어 | 2.333 | 2.059 | 2.400 | 3.030 | 0.015–0.018 |

- 총 28회 재생에서 `playing`과 시간 진행을 확인했다. 반복 재생 12회는 추가 음성 요청 0건이었다.
- 다음 문장 미리 받기가 있어도 바로 넘기면 생성 완료 전이므로 1.5–2.2초 기다렸다.
- 준비 단계의 별도 일본어 측정에서는 첫 재생 4.133초였다. 위 표는 전체 경로가 완료된 본 실행의 수치다. 첫 실행 변동성도 존재한다.
- 본 실행의 브라우저 `/api/study*` 완료 요청 35건은 모두 HTTP 200이었다. 문장 탐색으로 발생한 미리 받기 요청도 포함된다. 페이지 JavaScript 오류는 0건이었다.

### 지연 구조와 개선 우선순위

운영 리비전의 `app/api/study/audio/route.ts`는 공급자 응답을 `readLimitedBody`로 끝까지 읽은 뒤 응답한다. `lib/study-audio-client.ts`도 `response.blob()` 완료를 기다리고, `components/v2-speaker.tsx`가 그 뒤 Audio를 생성한다. 따라서 첫 음성은 전체 생성·전송이 끝나기 전 재생할 수 없다. 이번 측정만으로 공급자 생성 시간과 서버 간 네트워크 시간을 분리할 수는 없다.

1. 정적 스터디 문장은 검수된 음성을 미리 생성해 버전별 공용 캐시/CDN에서 제공하는 방식을 우선 검토한다. 언어·문장·목소리·모델·속도를 캐시 키에 포함해야 한다.
2. 동적 번역·대화는 공급자/브라우저가 지원하는 점진 재생 경로를 검증하고, 첫 오디오 바이트와 재생 시작 시간을 별도 관측한다. 스트리밍만 켜면 즉시 개선된다고 단정하지 않는다.
3. 현재 모든 Speaker의 `playbackRate`가 0.85로 고정돼 있다. 학습은 느리게 듣기를 유지하되 여행 번역에는 보통 속도를 제공하고 사용자가 선택할 수 있게 하는 편이 적절하다. 이는 시작 지연과 별개의 문제다.

## 스터디

운영 UI에서 **4개 언어 × 8개 상황 × 4개 레벨 × 10문장 = 1,280문장**을 실제 이전/다음 경로로 확인했다.

- 각 수업 10문장, 원문·한글 발음·뜻 표시, 문장 순서와 마지막 `학습 마치기` 버튼을 확인했다. 이 전체 탐색에서는 완료 버튼을 눌러 학습 이력을 만들지 않았다.
- 각 언어의 320개 원문 중 완전히 같은 문자열은 0건이었다. 의미상 유사도나 교육적 중복 0건을 보장하지는 않는다.
- 상황별 4개 레벨 카드가 구분되며, 레벨별 필터 16조합에서 상황 카드 8개씩 노출됐다.
- 문장 대화상자에서 가로 넘침은 없었다.
- 클럽·바는 짧은 인사/요청 → 취향 문답 → 이유/제안 → 거절/조율로 목표가 구분됐다. 스몰토크도 소개 → 취미 → 이유/경험 → 정중한 마무리로 구분됐다. 이는 구성 확인이며 공인 레벨 판정이 아니다.

### 발견: 고정 학습 자료의 발음 표기 오류

일본어 스몰토크에서 다음 예시를 확인했다.

| 위치 | 원문 | 운영 발음 표기 | 문제 |
|---|---|---|---|
| Lv.1 문장 1 | 韓国から旅行に来ました。 | 한국까라 료꼬니 끼마시따. | 韓国의 일본어 독음 대신 한국어 단어가 들어감. `캉코쿠카라`에 해당하는 소리여야 함 |
| Lv.1 문장 10 | ラウンジでお会いできて嬉しかったです。 | 라운지데 오아이데끼떼 우레시까따시따. | 문장 끝 です와 발음 표기가 불일치 |
| Lv.2 문장 1 | 週末はたいてい何をしますか。 | 슈마와 타잇테이 나니오 시마스카 | 週末의 독음 `슈마츠`에서 음절 누락 |

단순히 한글이 포함됐는지 검사하는 E2E로는 잡히지 않는다. **정적 발음 데이터 전수 검수**가 필요하며, 원어민 청음·번역 전문가 검수까지 완료했다고 주장하지 않는다.

## 번역과 학습 반영

`얼음 없이 커피 한 잔 주세요.`를 네 언어로 번역하고 해당 외국어 문장을 다시 한국어로 번역했다. 총 8개 방향 모두 이번 표본에서는 얼음을 빼 달라는 핵심 의미를 유지했다. 원문과 한글 발음이 UI에 표시됐다.

| 언어 | 한국어 → 외국어 응답 | 외국어 → 한국어 응답 |
|---|---:|---:|
| 일본어 | 2.355초 | 3.086초 |
| 태국어 | 3.890초 | 2.074초 |
| 영어 | 2.013초 | 2.056초 |
| 스페인어 | 2.106초 | 2.094초 |

보충 검증에서 일본어 `화장실은 어디에 있나요?` 번역을 자동 저장하고 `내 표현`에서 확인한 뒤 페이지를 새로 열어 유지되는 것을 확인했다. AI 대화의 `좋아! 같이 건배하자!`도 내 표현 저장을 확인했다. 보충 검증 후 해당 QA 계정의 저장 표현을 삭제해 0건으로 확인하고 로그아웃했다. 일반 QA 계정 자체는 삭제 API가 없어 남아 있다. 비밀번호/세션 쿠키는 결과물에 저장하지 않았다.

## AI 대화 — 응답 성공과 내용 품질을 구분

네 언어의 카페 대화는 모두 실제 API → 원문/한글 발음/한국어 뜻 UI 표시 → 음성 재생까지 성공했다. 응답 시간은 2.421–2.647초였다. 그러나 다음 내용 오류가 확인됐다.

### 높은 우선순위: 태국어 내 말 변환의 의미 변경

- 입력: `얼음 없이 커피 한 잔 주세요.`
- learnerPhrase.text: `ขอแฟหนึ่งแก้วไม่เอาหวาน`
- learnerPhrase.reading: `커 핝 깨우 마이 아우 완`
- learnerPhrase.meaning: `얼음 없이 커피 한 잔 주세요.`

태국어 원문의 `ไม่เอาหวาน`은 단맛을 원하지 않는다는 표현으로, 한국어 뜻의 얼음 조건과 맞지 않는다. 커피 표기와 한글 발음에도 문제가 있다. 반면 AI 상대 답변에는 `ไม่ใส่น้ำแข็ง`이 포함돼 있었다. **상대 답변과 사용자 말 변환은 별도 품질 경로이며, 번역 탭 통과가 내 말 변환 통과를 보장하지 않는다.**

이번 계정은 autoSaveChat=false여서 잘못된 문장이 실제 스터디에 저장되지는 않았다. 운영 코드의 `learnerTurn`은 원문과 변환문의 의미 일치를 별도 검증하지 않고 `parseRoleplay`의 형식/문자 검사와 제한적인 언어 가드를 거친다. 저장 전 핵심 조건(얼음/단맛/수량 등) 보존 검증과 보수적 저장 차단이 필요하다.

### 대화 흐름과 동적 발음

- 일본어: 커피에 얼음을 빼 달라는 입력에 `アイスコーヒーですね。氷なしでお作りしますか？`로 아직 정하지 않은 아이스 커피라고 단정하고 이미 요청한 조건을 다시 물었다.
- 영어: `One iced coffee with no ice, got it! Would you like that hot or iced?`로 아이스라고 확정한 뒤 hot/iced를 다시 물었다.
- 스페인어: `Un café sin hielo, por favor. ¿Algo más?`로 점원 역할이 손님의 부탁을 그대로 발화했다. `¿Algo más?`의 발음도 `알골 마스?`로 표시됐다.
- 일본어 건배 표본은 `やったー！乾杯！`로 반응해 이전의 갑작스러운 물 권유는 이 표본에서 재현되지 않았다. 다만 `乾杯`를 `칸바이`로 표기하는 발음 오류가 남아 있었다.

역할 유지, 확정된 주문 조건을 다시 질문하지 않는지, 변환문과 뜻의 일치, 동적 발음 품질을 각각 검증해야 한다. JSON 형식 성공을 학습 품질 성공으로 취급하면 안 된다.

## 화면 및 증거

- AI 대화 도구 모음의 버튼 정렬/겹침과 페이지 가로 넘침: 320/390/768/1440px 통과.
- 일본어·태국어 대화 캡처를 직접 확인했다. 나머지 번역·대화 캡처도 보관했다. 언어 선택 헤더가 유지되며 원문/발음/뜻의 별도 영역이 표시된다.
- 테스트 도구 자체의 초기 페이지 대기 및 레이블 탐색을 보정한 뒤 본 실행을 완료했다. 초기 테스트 선택자 오류를 앱 오류로 집계하지 않았다.
- 일반 계정 API로 프로필을 준비했으므로 가입 폼과 전체 레벨 체크 문답 UX를 검증한 것은 아니다.
- 공급자 내부 로그·인프라 구간별 지연·실기기 청음은 미확인이다.
