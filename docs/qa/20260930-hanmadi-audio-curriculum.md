# Hanmadi 음성 지연·4개 언어 학습/번역 검증

대상: `fix/hanmadi-audio-curriculum-20260930`, 기준 main `6f386c6`.
현재 문서는 작업 브랜치 검증이며 운영 반영 증거가 아니다.

## 음성

- 기존에는 같은 표현을 다시 들어도 매번 음성 생성 API를 호출했다.
- 언어+문장별 요청 병합과 탭 메모리 캐시를 적용했다. 최대 40개/10MB/10분이며 로그인 상태 변경·로그아웃·화면 해제 시 지운다. 진행 중 요청도 취소하고 뒤늦은 캐시 쓰기를 막는다.
- 수업에서 현재/다음 문장을 순차 준비한다. 버튼 포커스/포인터 진입도 준비를 시작한다. 아직 듣지 않은 미리 생성 문장은 최대 2개로 제한하여 단순 탐색의 일일 음성 할당량 소모를 제한한다.
- 실제 재생은 클릭으로만 시작한다. 다른 음성을 선택하면 이전 재생을 멈추며, 이전 요청의 늦은 응답이 새 재생을 덮지 않도록 했다. 실패는 캐시하지 않고 클릭 시 재시도한다.
- 로컬 Chromium에서 디코딩 가능한 오디오로 실제 `play()` 성공을 확인했다. 재듣기는 추가 제공자 요청 없이 64ms에 시작했다(자동화 동작 시간 포함). 합성 테스트 오디오이므로 운영 응답 시간이나 실측 개선율로 해석하지 않는다.
- 아직 준비되지 않은 첫 음성의 외부 제공자 생성 지연은 남는다. 미리 준비한 문장과 재듣기에서 대기를 줄이는 변경이다. 새 기기/새 탭/캐시 만료 후에는 다시 생성한다.

## 실제 운영 API 표본

기존 운영 `https://hanmadi-lake.vercel.app`에서 별도 일반 QA 계정으로 로그인하여 실제 번역과 음성을 호출했다. 자동 저장을 끈 상태이며 번역 결과의 `saved:false`를 확인했다. 종료 시 로그아웃했다. 인증 정보는 파일/로그에 보관하지 않았다. QA 계정 자체는 남아 있다.

입력: `얼음 없이 커피 한 잔 주세요.`

| 언어 | 번역 / 역번역 시간 | 음성 첫 요청 / 재요청 전체 시간 | 의미 확인 |
|---|---|---|---|
| 일본어 | 2342 / 2009ms | 4418 / 3072ms | 氷抜きでコーヒーを一杯ください。 → 얼음을 빼고 커피 한 잔 주세요. |
| 태국어 | 2991 / 2048ms | 3226 / 3134ms | ขอแฟเย็นไม่ใส่น้ำแข็งค่ะ: 커피 철자 누락, 요청하지 않은 차가운 음료 의미 추가 발견 |
| 영어 | 2334 / 2287ms | 3283 / 3461ms | Please give me a cup of coffee without ice. → 얼음 없는 커피 한 잔 주세요. |
| 스페인어 | 2635 / 2181ms | 2382 / 2796ms | Un café sin hielo, por favor. → 얼음 없는 커피 한 잔 주세요. |

모두 HTTP 200이었다. HTTP 성공만으로 번역 정확성을 판정하지 않았으며 태국어 결함을 별도 수정했다. 각 언어 단일 문장 표본이므로 모든 번역의 정확성을 보장하지 않는다.

## 태국어 번역 보완

- 번역 지시에 대상·수량·부정·온도 조건 보존과 정확한 발음 표기를 명시했다.
- 한국어의 얼음 없는 커피 요청에 한해 커피 단어/얼음 제외 누락 또는 원문에 없는 차가움·뜨거움 추가를 검사한다.
- 잘못된 응답은 기존 재생성 경로로 1회 수정한다. 계속 잘못되면 학습 자료로 넘기지 않고 오류를 반환한다.
- 실제 관측 오류, 올바른 커피 철자지만 온도 추가, 얼음 제외 조건 누락, 재시도 실패, 명시적 아이스 주문 허용을 회귀 검사했다.
- 이 검사는 임의 번역 의미 전체를 검증하는 기능이 아니다. 수정 후 실제 제공자/운영 결과 재확인은 배포 후 필요하다.

## 스터디와 E2E 범위

- 일본어·태국어·영어·스페인어 × 8상황 × 4레벨 × 10문장 = 1,280개 화면 노출 검사.
- 언어별 320개 문장 중복, 언어 태그, 상황별 4수업, 레벨별 8수업, 이전/다음, 수업 종료/진도 유지, 모바일 가로 넘침 검사.
- 7개 상황은 원문·한글 발음·한국어 뜻·진행 안내가 데이터와 일치하는지 검사. 클럽·바는 별도 원본을 사용하므로 레벨 제목·고유 문장·언어·레이아웃 중심으로 검사했다.
- 한국어 학습 목표/내용 검토: Lv1 구체적 짧은 요청, Lv2 질문과 확인, Lv3 이유와 선호·비교, Lv4 문제 해결·정중한 거절·대안 협의로 구분된다. 카페 Lv1 주문과 Lv4 주문 착오 해결 화면도 직접 검토했다.
- 4개 언어 한국어→학습언어 UI, 학습언어→한국어 API, 오류 재시도, 자동 저장/중복 방지/동의/사용자 격리 검증. 로컬 E2E 모델 제공자는 고정 응답이므로 실제 모델 검증은 위 운영 표본과 구분한다.
- 이번 검사에서 교재 문장 전면 재작성은 하지 않았다. 데이터와 화면의 일치 검사는 1,280개 문장에 대한 원어민 감수 증거가 아니다.
