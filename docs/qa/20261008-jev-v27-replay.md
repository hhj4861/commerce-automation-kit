# discovery-v2.7 고정 입력 재생 평가 — 2026-10-08

10/05 [v2.6 고정 입력 평가](20261005-jev-v26-final.md)에서 기록한 JEV 판정과 Codex 재검수 응답에, v2.7 규칙만 다시 적용해 판정 변화를 확인했다. **네트워크·모델 호출은 0회, 비용은 0이다.** 운영 품질 인증이 아니다.

## 방법

- 입력: 사례별 재검수 직전 상태(`snapshot-2.json`, JEV checks 포함)와 Codex 응답(`native-response.json`). 공개 스냅샷에서 빠진 요청 입력은 `results.json`에서 채웠다.
- **대조 재생**: rubric을 v2.6으로 두고 다시 적용했다. 재검수를 거친 10건 모두 10/05 최종 판정과 사유를 그대로 재현했다(재생 방식 검증).
- **v2.7 재생**: rubric만 `discovery-v2.7`로 바꿔 같은 응답을 적용했다.
- 재검수를 거치지 않은 5건(eiffel-2·3, haesol-2·3, baram-2)은 JEV·서버 판정이라 v2.7 규칙의 영향을 받지 않는다.

따라서 이 결과는 **"v2.7이 기존 정상·오류 사례의 판정을 바꾸지 않는다"**는 회귀 확인일 뿐, 새 규칙의 효과 증거는 아니다. 새 규칙을 검증하려면 해당 경로를 일부러 겪게 하는 새 사례가 필요하다.

- 불확실 필드를 `not_applicable`로 바꾸는 재검수 응답
- 위치 근거가 없는 대상의 실제 초안 생성
