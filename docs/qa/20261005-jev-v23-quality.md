# JEV 사실 포함·근거 분리 검수 — 2026-10-05

**1순위 품질 개선은 미완료다.** v2.3 두 시안을 구현해 비교했지만 근거 있는 연출 제안 3개의 보류를 해결하지 못했다. 기본 검수는 v2.2를 유지하며 v2.3은 내부 평가용 명시 선택으로만 격리했다. 운영 배포·클라이언트 활성화·머지는 하지 않았다.

## 구현과 검증 범위

- 원문 전체·공식/합성 근거를 유지하면서 6개 필드의 사실 포함 여부와 근거 검사를 분리했다. 같은 요청의 17문항(이력 포함 18문항)이며, 다른 답변 때문에 원문 검사를 건너뛰지 않는다.
- 기존 신뢰도/선택 확률/확률 차이 0.8/0.8/0.2, 오류 보류, 확정 모순 우선, 사람 승인을 유지했다. 구버전 진행 요청과 완료 결과 재호출도 보존한다.
- 공통 `score_review`로 실제 서비스와 평가의 검증/판정 규칙을 일치시켰다. 기본 생성자는 v2.2이며 API 입력이나 환경변수로 실험 버전을 켜는 경로는 없다.
- 기준 main `e2d39bd`. 로컬 Python **54개**, JS HTTP·런타임·Shopshorts **15개** 통과. HTTP→Python→격리 DB→재호출에는 모델 모의 응답을 사용했다. 실모델 전체 후보 E2E 성공을 뜻하지 않는다.

## 고정 실모델 결과

기존 회귀 15개와 새 대상 15개, 고유 사례 30개를 사용했다. 시안 A는 회귀 15개와 새 대상의 구버전/새버전 30개를 비교했고, 시안 B는 사전에 정한 중단 기준에 따라 회귀 15개만 검사했다. 총 60개 필드 결과·105개 개별 답변이며 독립 표본 60개가 아니다.

| 회귀 15개 | 기존 v2.2 기록 | 시안 A(긴 지시) | 시안 B(짧은 지시, 최종 실험 코드) |
|---|---|---|---|
| 근거 있는 사실 문장 3개 | 모두 통과 | 모두 통과 | 모두 통과 |
| 같은 사실을 담은 연출 제안 3개 | 모두 보류 | 모두 보류 | 모두 보류 |
| 순수 연출 3개 | 모두 통과 | 모두 보류 | 모두 통과 |

기존 v2.2는 [앞선 고정 비교 기록](https://github.com/hhj4861/commerce-automation-kit/blob/b9d93cc/docs/qa/20261005-jev-fixed-field-comparison.md)이며 이번에 재호출한 동시 대조군이 아니다. 시안 B의 연출 제안 support confidence는 안양 0.76, 박물관 0.71, 과학관 0.52로 모두 기준 미달이다. 시안 A보다 일부 점수가 달라졌다는 이유로 품질 통과를 선언하지 않는다.

새 대상 15개는 시안 A에서 v2.2와 짝지어 평가했다. 에펠탑의 근거 있는 도식 제안은 보류→통과했지만 순수 연출은 통과→보류로 바뀌었다. 가상 사업의 정상 제안은 두 버전 모두 보류됐고, 상충 자료·모호한 지시 대상·입력 지시 공격도 모두 보류됐다. 평가 자료에서 잘못된 통과는 관측되지 않았지만 일반적 안전성을 보장하지 않는다. 시안 B는 회귀 기준 실패 때문에 새 대상까지 확대하지 않았다.

## 사용자 독립 검토

예상 답을 공개하지 않고 받은 원문: “1 통과, 2탈락 3보류 4통과 5탈락 6.20~30이라고 하면 됨”. 사용자 답변은 원래 작성자 라벨을 덮어쓰지 않고 별도 보존했다.

| 4 예약 12/20 결과의 타 매장 실험 | 통과 | 보류 / 보류 | 정상 사업 제안의 보류 해결 |

6번 답변은 원문에 대한 ‘통과’ 라벨로 바꾸지 않았다. 상충하는 점 추정 두 개만으로 실제 측정 범위를 확정할 수 없으므로 “자료 A는 20m, B는 30m로 기록하며 불일치가 있다”처럼 출처와 불확실성을 보존해야 한다. 수정 문구를 실제로 생성하거나 실모델에 검증한 것은 아니다.

5번은 작성자 초기 라벨(보류)과 사용자 기준(탈락)이 다르다. 지원 근거 검사 외에 기존 사업 가치 질문에 수익 보장 거절 기준이 있지만, 이번 필드 평가만으로 전체 후보가 확실히 거절된다고 주장하지 않는다.

## 잔여작업과 진행 판단

임계값 완화나 정상 제안을 통과시킬 때까지 동일 문구를 반복 호출하는 방식은 채택하지 않았다. 이번 v2.3은 **실험 구현·검증 기록이며, 품질 개선 완료본이 아니다.**

다음 설계 후보는 저신뢰 보류에 한정한 언어모델 재검토 또는 사람 수정 경로다. 단순히 두 번째 모델의 결론을 채택하지 않고 전체 원문·출처·모순·수익 보장 규칙을 보존하며, 정상 제안·잘못된 통과·지연·총비용을 새로운 평가 자료로 비교해야 한다. 이 대체 경로는 아직 구현하지 않았다. 전체 후보 검증과 운영 전환도 계속 미완료다.
