# 질문에 답하는 조사·대본 연결

- 목표: 운영 수원 서북공심돈 검증에서 확인한 외형·목적 반복과 작동 과정 누락을 줄인다.
- 담당/범위: Codex 단독, fix/shopshorts-causal-research. explainer-production의 조사 지침과 studio-scenario의 작성·보완 지침만 변경한다.
- 기준: #219 source 5881464 / #220 production d0b128d. 승인된 배포는 완료했고 실제 조사→작성→보완→검토 후 내용 불합격.
- 실제 근거: 첫 질문은 “왜 성벽 밖으로 나와 있을까요?”였지만 본문은 “방어 공간 자체를 성벽 바깥에 둔 겁니다”로 모양을 재서술했다. 검토는 출처에 있는 화포 사용 기능을 구체적 행동으로 설명하지 않은 점과 연도/종류 나열에 시간을 쓴 점을 지적했다. 상세 보관/조회는 운영에서 실제 확인했다.
- 수정: 조사 단계에서 먼저 약속한 질문의 인과 근거와 같은 대상의 사용 과정을 찾고, 단순 소개 자료만으로 끝내지 않는다. 작성 단계는 확인된 행동을 대사·화면에 연결하고 목적/외형의 반복과 부수 정보로 인과를 대체하지 않는다. 사실이 부족하면 만들거나 질문을 몰래 바꾸지 않는다.
- 불변: JSON 계약, 출처 검증, 독립 검토 기준, 1회 보완, 모델·시간 제한, 스타일·음성·예산, 과금 게이트. 런타임 조사/대본 생성 공통 경로에만 적용한다.
- 완료 기준: 관련 회귀 검사 및 두 대상 브랜치 검증/PR 준비. 실제 생성 품질 개선은 새 머지 승인 후 운영 실검증으로 확인해야 한다. 프롬프트 변경이나 고정 fixture 검사를 의미 품질 개선 성공으로 간주하지 않는다.
- 현재: 후속 변경 준비 중, 운영 미반영. 기존 불합격 대본은 보존하며 새 유료 생성은 하지 않는다.
