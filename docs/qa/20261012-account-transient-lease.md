# Shopshorts 계정 작업의 일시적 연결 실패 복구

- 목표/담당: 현재 Codex, 운영 실생성 중 발견한 LLM 브로커 갱신 실패 보완.
- 기준: deploy/shopshorts bea0124. 범위: 계정 워커와 회귀 테스트만.
- 증거: 운영 launchd 읽기 진단 3회 중 2회 성공(3.1초/12.3초), 1회 20초 TimeoutError. 기존 코드는 한 번의 갱신 실패로 생성 AbortController를 중단했다.
- 변경: 전송 Timeout/fetch 오류 및 429/502/503/504만 최대 1회 재시도. CAS write 응답 유실은 저장 결과 확인 후 완료 처리. 취소·인증 오류·다른 소유자는 재시도로 복원하지 않음. 갱신 임대 120초, 기존 전체 작업 마감 유지.
- 완료 기준: 응답 유실 시 중복 실행 없음, 취소 보존, 영구 오류 무재시도, 장애 재시도 유한, 기존 계정/시나리오 테스트.
- 검증: 계정·Codex·시나리오 관련 51개 검사 통과. 신규 검사는 저장 응답 유실, 일시적 읽기 실패, 취소 중 인증 복원 방지, 401 무재시도, 유한 재시도를 확인.
- 상태: 검증 완료, PR 준비. 아직 운영 적용 아님.
