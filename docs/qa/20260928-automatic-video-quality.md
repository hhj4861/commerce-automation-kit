# 자동 제작 시네마틱 엔진 검증

## 범위와 상태

- 기준: `origin/main` dd934be (대시보드 통합 PR #49 포함).
- 구현: `feat/automatic-video-quality`, `/private/tmp/cak-automatic-video-quality`.
- 새 자동 프로젝트에 `brief.productionStyle=cinematic`을 저장한다. 기존 프로젝트는 변경하지 않는다. 대본 승인·발행 검수 게이트를 유지한다.
- 이 기록은 작업 브랜치의 로컬 검증이다. 운영 배포·실제 Higgsfield 생성 결과의 미적 품질 검증은 아직 수행하지 않았다.

## 참조 관찰

사용자가 제공한 `KakaoTalk_Video_2026-09-28-14-16-50.mp4`를 로컬 ffprobe와 4초 간격 접촉 시트로 분석했다. 약 56.842초, 1280×720, 24fps, AAC 오디오가 있다. 어두운 건축물, 서가, 손·사물의 근접 화면, 숲과 도시의 넓은 화면, 제한된 색감, 짧은 자막과 마지막 타이틀이 관찰된다. 음성 내용·음악 라이선스·원본 생성 모델은 확인하지 않았으며 추정하지 않는다. 참조 파일·프레임·대본·음성을 프로젝트 산출물이나 테스트 미디어로 재사용하지 않았다.

## 구현

1. 구독 LLM이 공통 팔레트·조명·인물·소품을 `visualStyle`로 설계하고 장면별 `shot`·`camera`를 작성한다. 보통 4~8초, 최대 12초 컷으로 의미와 구도를 변화시키도록 지시한다. 누락·잘못된 연출 메타데이터는 재생성 안내를 반환한다. 사용자가 요청한 화풍이 우선이다.
2. Higgsfield/Google에 같은 공통 연출과 해당 대사, 장면 설명, 앞 장면의 연결 단서를 전달한다. 기존 모델·크레딧 확인·유료 요청 영수증·중복 방지 흐름을 유지한다. 이미지/영상 구분은 승인할 대본에 포함된다.
3. 초기 자동 조립 전에 음성을 생성·저장하고 실제 길이를 측정한다. 클립은 계획 길이와 `음성 길이+0.2초` 중 긴 쪽을 사용한다. 30초 클립 한도·형식의 총길이 한도를 넘으면 명시적으로 대본 수정 안내를 한다. 임의 가속이나 대사 잘라내기로 숨기지 않는다. 이미 편집된 타임라인은 자동으로 다시 맞추지 않는다.
4. 문장·공백 중심의 최대 두 줄 자막을 만든다. 세로 18자/줄, 가로 32자/줄; 사용자 편집·삭제는 기존 편집기에서 가능하다. 자막 시간은 측정한 장면 음성 길이 안에서 글자 비중으로 배분한다. **단어별 음성 강제 정렬은 아니다.**
5. 정지 이미지에 최대 6%의 완만한 줌·이동, 화면 채움, 고품질 스케일링을 적용한다. 영상은 소스보다 길 때 마지막 프레임을 유지한다. 1080p/30fps, x264 medium/CRF18. 기존 프로젝트의 렌더 설정은 유지한다.
6. 편집 미리보기도 같은 카메라 경로·영상 끝 유지 규칙을 사용한다. 장면이 완료되고 음성을 준비하는 단계는 별도 문구로 안내한다.

FFmpeg 필터의 동작은 [공식 zoompan/tpad 문서](https://ffmpeg.org/ffmpeg-filters.html)와 실제 렌더로 확인했다. 새 외부 API나 비공식 생성 경로는 추가하지 않았다.

## 검증 결과

- Shopshorts 전체: **289/289 통과** (`npm test -w @cak/app-shopshorts`).
- 변경된 연출 오류 안내 이후 관련 테스트 21개 재실행 통과.
- 마지막 길이 오류 전달 보완 후 자동 제작·음성·시네마틱 테스트 19개 통과. 클립 한도 초과는 완료 HTTP 요청 전에 실행기에서 감지해 사용자가 수정할 수 있는 오류를 저장한다.
- Pages API 엔트리 esbuild browser bundle 통과.
- 신규 실제 FFmpeg 테스트: 1920×1080, 타임라인 프레임 수 일치, 이미지 시작/후반 프레임 차이, 영상 끝 유지, 원래 2초 컷을 넘는 2.6초 테스트 음성의 마지막 부분 유지 확인.
- 음성 재시도 테스트: 두 음성을 생성한 뒤 재실행 시 생성 호출 증가 없음. 기존 편집 타임라인·사람 승인 게이트 유지.
- 로컬 Chrome: 0초 scale(1) → 5초 scale(1.03766), 영상 13초 위치에서 2초 소스의 currentTime=1.966666/loop=false 확인. 한국어 자막 줄바꿈과 타임라인 구간 노출 확인.
- 브라우저 fixture는 합성 테스트 패턴·사인파이며 유료 생성·실제 음성 품질을 검증한 것으로 해석하지 않는다. 읽기 전용 HTTP API만 제공한다.
- 최초 브라우저 fixture 실행의 tsx IPC는 샌드박스 EPERM으로 종료됐다. 승인된 격리 로컬 서버 실행으로 재검증했다. 운영 인증 설정은 수정하지 않았다.

재현: `node apps/shopshorts/test/cinematic-browser.mjs` (기본 127.0.0.1:5219, 종료 시 자기 임시 데이터 정리).

## 운영 전환과 남은 품질 확인

PR 머지 승인 후 Pages, 미디어 제작 워커, 구독 LLM 계정 워커를 같은 리비전으로 반영해야 한다. Pages만 배포하면 예전 계정 워커가 새 연출 메타데이터를 만들지 못할 수 있다. 검증 후 새 자동 제작 프로젝트를 생성한다.

실제 생성 품질은 모델 출력과 기획에 영향을 받는다. 승인된 주제로 Higgsfield·TTS를 사용하는 한 편을 만든 뒤 인물·색감 일관성, 대사와 장면 관계, 청음, 자막 호흡을 비교해야 한다. 이번 변경은 배경음 자동 선택/생성, 효과음 설계, 단어별 강제 정렬, 컷 간 인물 동일성 보장을 추가하지 않는다. 기존 사용권 있는 배경음 편집 기능은 유지한다.
