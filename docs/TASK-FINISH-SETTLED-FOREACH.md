# allSettled 직접 forEach 출력의 종료 증거 검증

## 문제와 변경

`const r = await Promise.allSettled([...]); r.forEach(text);`의 결과에는 인덱스가 없다.
기존 완료 훅은 인덱스를 추가한 출력만 해석하므로, 실제 자동 승인 거절 기록이 있어도
실행되지 않은 호출을 종료 미확인으로 남긴다.

수정은 리터럴 호출 배열과 변형 없는 `forEach(text)` 문법만 허용한다.
출력 순서로 위치를 판별하되 다음 기존 검증은 모두 유지한다.

- 같은 세션·턴·외부 호출에 속한 요청과 응답이 정확히 하나씩 존재한다.
- 거절 결과와 대응되는 미완료 Pre 기록은 각각 하나뿐이다.
- 다른 명령은 명령 문자열과 종료 코드가 일치하는 실제 native 종료 이벤트를 가진다.
- 거절된 호출에 native 실행 이벤트가 있으면 모순으로 보고 거부한다.
- 거절은 `declined`로 기록하며 성공 종료 코드로 바꾸지 않는다.
- 현재 파서 버전에서 누락된 binding을 사후 추측하지 않는다. 이전 버전에서 지원하지
  않던 이 문법에만 과거 증거 복원을 허용한다.

상태 파일을 직접 수정하거나 실행·거절 기록을 만들어 넣는 기능은 없다.

## 검증과 적용

```sh
python3 tools/test-task-finish-settled-foreach.py
python3 tools/task-finish-settled-foreach.py
python3 tools/task-finish-settled-foreach.py --apply --expect-sha256 <직전 검증의 해시>
python3 ~/.codex/hooks/task-finish/gate.py reconcile
```

설치 전 원본 SHA-256 일치와 치환 지점을 검사한다. 백업을 보존하고 원자적으로 교체한다.
이미 설치됐다면 변경하지 않는다. 새 파서 버전은 16이다.

2026-09-22: 문법 변조, 출력 순서·필드 변조, native 증거 누락·중복·불일치,
현재 binding 누락, 거절과 실행 이벤트의 모순을 포함한 테스트 13개 통과.
현재 세션의 실제 기록 대조 명령은 자동 승인 검토에서 비공개 세션 기록 접근으로
거절됐다. 따라서 이 패치는 아직 전역 훅에 설치하지 않았으며 실제 미확인 호출의
복원 완료도 주장하지 않는다. 원래 거절된 다른 세션의 기록 조회를 재실행하지 않는다.
