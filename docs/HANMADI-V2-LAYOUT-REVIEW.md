# Hanmadi 언어 표시·로그인 상태·Claude 연결 UX

2026-09-29. 운영 사이트를 Chrome에서 직접 확인하고 격리 로컬 앱에서 수정 화면을 재검증했다.

## 직접 확인

- 운영 사이트는 대표 계정으로 로그인되어 로그아웃만 표시했다. 이 확인은 브라우저 화면의 계정 표시를 근거로 하며, 실제 계정의 학습 언어는 변경하지 않았다.
- 운영 설정 화면은 아직 이전 팝업이었다. PR #68의 main 머지와 운영 배포는 별개다.
- 상단 언어 선택 폭은 112px이고 좌우 여백 합이 58px라서 긴 언어명을 표시할 공간이 부족했다.
- 로컬 320px Chrome에서 스페인어 전체 표시와 로그인 전 버튼을 확인했다. 격리 테스트 계정으로 로그인한 후 설정의 로그인됨·계정명·학습 계정 표시, Claude 연결 안내가 열리는 것도 확인했다.

## 수정

- 선택 칸을 142px로 늘리고 네이티브 선택 동작을 유지하면서 화살표 공간을 따로 확보했다. 긴 언어명이 잘리지 않으며 언어 선택은 왼쪽, 계정 관련 버튼은 오른쪽에 유지한다.
- 기본 버튼 글자는 가운데 정렬한다. 수업 카드와 설정 행의 개별 정렬은 시안대로 유지한다.
- 설정 상단에 로그인됨·계정명·계정 종류·기록 저장 대상을 명시한다. 로그아웃 후에는 로그인 버튼이 표시된다.
- Claude 연결 시작 버튼을 키 입력 전부터 사용할 수 있게 했다. 누르면 공식 Console 링크와 API 키 입력 순서를 안내한다. 키 확인·연결은 키와 기존 보관 동의가 있어야 가능하고, 취소하면 입력 키를 지운다.

## Claude 인증 범위

요청한 구독 OAuth 인증 코드/토큰을 한마디가 수집해 LiteLLM에 전달하는 방식은 구현하지 않았다. 공식 문서는 타사 자체 앱의 Claude.ai 로그인 및 사용자 구독 자격을 통한 대리 요청, 자격·세션 토큰 수집을 제한한다. 사용자가 수정하지 않은 Claude Code 자체에 로그인하는 호스팅 예외는 일반 회화 앱의 토큰 수집 허용과 다르다. 따라서 기존 공식 API 키 방식의 연결 동선만 개선했다. API 사용료는 구독과 별도다.

근거(확인일 2026-09-29): https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use
