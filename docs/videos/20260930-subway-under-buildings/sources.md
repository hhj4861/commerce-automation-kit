# 사실 확인 — 지하철 굴착 3D 쇼츠

- [Herrenknecht EPB Shield 공식 설명](https://www.herrenknecht.com.cn/produkte/productdetail/%E5%9C%9F%E5%8E%8B%E5%B9%B3%E8%A1%A1%E5%BC%8F%E7%9B%BE%E6%9E%84%E6%9C%BA/): 굴착토를 지지 매질로 사용, 굴착실 압력과 스크루 배출량 제어, 세그먼트 조립 및 뒤채움.
- [Crossrail 실제 시공 기술 보고서](https://learninglegacy.crossrail.co.uk/documents/crossrail-western-running-tunnels-crossing-of-london-underground-victoria-line-and-bakerloo-line-assets/): 굴착면 압력, 굴착토 배출량, 뒤채움 주입과 계측의 결합. 지반 변형을 최소화하는 제어이며 무침하 보장이 아님.
- [Crossrail 터널 시공 방법 원문](https://learninglegacy.crossrail.co.uk/wp-content/uploads/2023/03/d08tunnelconstructionmethodology1.pdf): 프리캐스트 세그먼트와 배면 공극의 그라우팅, 지반·건물 모니터링.

이 영상은 연약지반용 토압식 쉴드 TBM의 원리를 단순화한 설명이다. 모든 지하철·지반에 동일한 공법을 사용한다는 주장은 하지 않는다. 사례의 수치와 치수는 일반 설계값으로 전용하지 않는다. 외부 영상·사진·도면을 복제하지 않고 자체 3D 형상을 사용한다.
