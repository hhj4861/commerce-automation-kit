# TGV 2탄 — 사실 확인 / 2026-10-01

1. [LPKF — Glass Core Substrates](https://lide.lpkf.com/en/applications/glass-core-substrates): TGV가 유리 양면의 RDL을 연결하며, 위치·벽면·균열·패널 균일성이 중요함. 제품의 성능 광고 수치를 일반 표준이나 실측 사실로 사용하지 않는다.
2. [LPKF — LIDE process](https://lide.lpkf.com/en/technology/lide): 초단펄스 레이저 변성 뒤 선택적 습식 식각. 모든 TGV가 이 방식으로 만들어진다고 표현하지 않는다.
3. [Atotech — integrated wet metallization, 2026-07-28](https://www.atotech.com/mks-atotech-introduces-integrated-wet-metallization-process-for-glass-substrates/): 표면 접착 촉진 → 무전해 구리 씨앗층 → 펄스 도금의 한 가지 공정 예. 가공과 금속화가 별개 과제임. 광고상 무결함 주장을 모든 생산품에 보장하지 않는다.
4. [Atotech — VitroCoat GI](https://www.atotech.com/products/electronics/surface-treatment/vitrocoat-gi/): 유리와 금속 접착, 고종횡비 내부의 균일한 피복 과제.
5. [Atotech — InPro Pulse TGV](https://www.atotech.com/wp-content/uploads/2025/09/InPro_PulseTGV_poster_final.pdf): 구리 충진, seam void 감소 및 제어. 주조나 아래에서 액체가 단순히 차오르는 것으로 묘사하지 않는다.
6. [SCHOTT — Glass Panels technical details](https://www.schott.com/en-us/products/glass-panels-p1001142/technical-details): 조절된 CTE, 미세 배선과 TGV 가공에 맞는 소재. 수치가 다른 재료를 무조건 같은 것으로 취급하지 않는다.
7. [Research: copper-metallized TGV aging](https://www.nature.com/articles/s41378-026-01160-0): TGV의 온도와 장기 신뢰성은 별도 검증 과제. 실험의 특정 조건을 모든 제품으로 일반화하지 않는다.

## 화면과 표현 한계

- 원본 3D 개념 모형. 치수·변형·빛 점 속도는 확대/단순화하며 실제 공정 조건이나 전자의 이동 속도가 아니다.
- 유리는 절연, 선택된 금속 경로는 연결. 유리 전체가 전기가 통하는 물질로 변하는 것이 아니다.
- 관통구멍 형성, 금속화, 양면 배선·접점 연결, 검사는 다른 단계다.
- 충진 방식은 여러 가지다. 공정 예를 산업 전체의 유일한 표준으로 표현하지 않는다.
- 기업은 공정·소재 제공 사례로 짧게 언급하고 점유율·우열·특정 AI 제품 채택을 추정하지 않는다.
- 일상 영향은 시스템 설계의 기반이라는 설명이며 앱 성능·가격의 직접 개선을 보장하지 않는다.
- 실리콘 계산 소자, 실리콘 관통 TSV, 유리 코어의 TGV를 구분한다.
- 보유 Higgsfield 가상 공장 도입부 6초는 AI 재현으로 표기하고, 실제 레이저/도금 장비 영상이라고 주장하지 않는다.

8. [SK hynix — TSV](https://news.skhynix.com/en/creating-new-values-in-dram-using-through-silicon-via-technology-for-continued-scaling-in-memory-system-performance-and-capacity/): HBM/메모리 적층의 실리콘 관통 연결. TGV와 관통 대상 및 적용 위치를 구분한다.
