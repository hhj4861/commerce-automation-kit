## 생성·편집 기록

기존 Cloudflare 보관 Higgsfield 연결과 공식 CLI를 사용했다. Seedance 2.0 std 1080p 영상 5개와 Nano Banana 2 2k 이미지 1개를 생성했다. 사전 잔액 1325.1크레딧, 실시간 견적 합계 371크레딧이었다. 원리 도해는 추가 영상 생성 비용 없이 SVG/FFmpeg로 렌더했다.

실내 장면으로 요청한 s7이 유압 기계 클로즈업으로 생성됐다. 이 결과를 내용에 맞는 s6의 댐퍼 설명에 사용하고, s7은 두 건물의 흔들림을 비교하는 직접 제작 도해로 교체했다. 당초 생성한 s6의 공·수직 피스톤 컷은 사용하지 않았다. 추가 유료 재생성은 하지 않았다. 실제 생성 영수증은 로컬 캐시 media-receipts.json에, 생성 job ID·비용·사용/미사용 컷 대응은 brief.json과 project.json의 mediaProvenance에 보존한다. 인증 값은 저장하지 않는다.

이미지/영상은 AI로 재현한 개념 화면이며 실제 타이베이 101 내부 촬영이나 정확한 시공 도면으로 제시하지 않는다. 영상에 AI 재현 표시를 넣었다. 원리 도해의 진폭과 비율은 과장되었고 실제 시뮬레이션·감소율 측정값이 아님을 표시한다.

## 재현

제작 레시피는 애니메이션 및 Higgsfield 지원 checkout을 CAK_ENGINE_ROOT로 사용한다. TAIPEI_CINEMATIC_CACHE는 미디어·작업 영수증 캐시, TAIPEI_NARRATION_CACHE는 remote-narration 하위 폴더가 있는 원음 캐시다. 기본값은 produce.mjs를 참고한다. 원음은 TTS 실행 36586659576에서 생성됐으며 새 TTS가 필요하면 별도 사용량이 발생한다.
