## 재현

1. 기존 영수증 및 출력 상태를 확인한다. 유료 도입부는 `produce.mjs cost` 조회 후 예산 내 최초 실행만 `generate`한다. 실패/미확정 접수는 공식 이력을 확인하며 자동 재제출하지 않는다.
2. `produce.mjs tts`의 원격 실행을 확인하고 `narration` artifact를 캐시의 `remote-narration`으로 회수한다. 기존 음성이 있으면 새 호출하지 않는다.
3. `align.py --cache <캐시> --model-dir <기존 로컬 Whisper 모델>` 실행.
4. Blender에서 `scene.py -- --cache <캐시>/3d --preview`로 구도를 확인한 뒤 같은 명령에서 `--preview`를 빼 본 렌더링한다. 중단 파일은 ffprobe로 확인하고 해당 장면만 `--force --shot <id>`로 재렌더링한다.
5. `edit.py --cache <캐시> --font-dir <Pretendard 폴더> --output <롱폼 경로>`; 숏폼은 `--short` 추가 및 별도 출력 경로. 원본 완성본을 덮어쓰는 경로를 지정하지 않는다.
6. 최종 디코딩·A/V 길이·자막 폭/타이밍·긴 무음·장면별 화면을 확인한 후 결과 보고서를 확정한다.

기술 검증의 통과가 레퍼런스와 동일한 미술 품질을 보장하지 않는다. 이번 편은 신규 공간·구도 기준을 처음 적용하는 제작이며 실제 완성본을 함께 검토한다.

## 최종 검증 — 2026-10-02

- 두 파일 모두 H.264/AAC, 24fps. 롱폼 1920×1080, 숏폼 1080×1920. 영상/음성 길이가 각각 327.333초와 77.125초로 일치한다.
- 전체 파일 디코딩 통과. -40dB 기준 1.3초 이상 무음, 98% 이상 어두운 화면이 0.3초 이상 이어지는 구간은 발견되지 않았다.
- 실제 통합 음량은 두 영상 모두 -17.6 LUFS. True Peak는 롱폼 -0.7dBFS, 숏폼 -0.9dBFS로 측정했다.
- 자막 105개/35개 시간 겹침·화면 폭 검사 통과. HBM·TSV·TGV·H200은 자막에 표준 약어로 표시한다.
- 롱폼 51개, 숏폼 21개 샘플 프레임을 검토했다. 최종 숏폼의 8초/12.3초 화면도 추가 확인했다. 확대 장면의 의도적인 부품 부분 구도와 자막 잘림을 구분했다. 전 프레임 수동 청음·시청을 의미하지 않는다.
- DRAM 접점 336개의 시작/끝 부착 좌표 검사 통과. 움직이는 검사 렌즈도 본체와 일정한 상대 위치를 유지한다. 비유 장면의 가로대를 칸막이 높이에 맞췄다.
- 수치 내레이션은 로컬 Whisper medium의 독립 인식에서도 H200·141GB·초당 4.8TB로 확인했다. 자동 인식은 사람의 청음 평가와 구분한다.
- Higgsfield 추가 생성 없이 무료 로컬 렌더·크롭을 보정했다. 숏폼용 유료 영상·음성 추가 생성은 없다.
