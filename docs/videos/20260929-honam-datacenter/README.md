# 메가 데이터센터, 왜 호남인가

요청: 건축학 카테고리, 애니메이션, 세로 쇼츠 1분. 주제는 ‘메가 데이터센터가 호남에 위치해야 하는 이유’.

- 결과 영상: [honam-datacenter-60s.mp4](honam-datacenter-60s.mp4)
- 대본·장면·실측 음성 길이·자막: [project.json](project.json)
- 장면 미리보기: [storyboard.jpg](storyboard.jpg)
- 기술 검증: [verification.json](verification.json)
- 재현 레시피: [produce.mjs](produce.mjs)

이 산출물은 **로컬에서 만든 검토용 영상**이다. 운영 대시보드의 프로젝트로 등록하거나 YouTube 등에 업로드하지 않았다. 건물·태양광·저장장치·냉각·전력 흐름은 이번 편을 위해 작성한 원본 SVG 도해다. 실제 시설 사진이나 조감도가 아니다. 기존 앱의 범용 아이콘 애니메이션보다 주제에 맞게 구성한 일회성 영상이며, 이 도해를 앱의 생성 기능에 적용한 상태는 아니다.

음성은 ElevenLabs의 ‘진건 · 차분한 남성’을 사용한다. 기존 Cloudflare 시크릿 서비스를 통해 메모리에서 인증을 읽으며, 인증값은 산출물에 저장하지 않는다. Higgsfield·Gemini 영상 생성은 사용하지 않으며 배경음악은 넣지 않았다. 대본 전달과 도해의 설명에 집중한다.

이번 제작에서 로컬 네트워크의 TLS 인증서 검증이 실패하여, 저장소에 이미 구성된 `tts-remote.yml`을 사용했다. [원격 음성 생성 실행](https://github.com/hhj4861/commerce-automation-kit/actions/runs/36543974986)은 성공했고 8개 음성을 내려받아 로컬 제작 캐시로 가져왔다. TLS 검증을 끄거나 인증서를 임의로 신뢰하도록 변경하지 않았다.

## 대본과 해석 범위

검증 결과: 정확히 60.000초, 1080×1920, 30fps/1800프레임, H.264 + AAC 스테레오. 대사 실측 총 50.434초이며 모든 장면에서 음성이 끝난 후 여유 시간을 확보했다. Chrome 실제 재생·오디오 디코딩·끝부분 탐색과 ffmpeg 전체 디코딩을 통과했다. 8장면 자막의 표시 및 겹침 여부를 이미지로 확인했다. 오디오 신호 존재와 디코딩을 확인한 것이며 별도의 청음·음성 전사 검증을 했다는 의미는 아니다.

1. 메가 데이터센터, 왜 호남일까요? 답은 땅값보다 전기에 있습니다.
2. 서버는 밤낮없이 전기를 쓰고 열을 냅니다. 전력과 냉각이 먼저죠.
3. 호남의 기회는 재생에너지입니다. 전남은 출력 제한을 줄일 저장장치도 추진하죠.
4. 전기를 멀리 보내는 대신, 데이터를 전기가 있는 곳으로 옮기는 겁니다.
5. 서버동과 변전소, 냉각 설비를 하나의 캠퍼스로 설계할 기회도 생깁니다.
6. 이런 입지 분산은 수도권에 몰린 전력 수요를 나누는 방향이기도 하죠.
7. 물론 조건은 있습니다. 계통 연결, 냉각과 용수, 통신망을 검증해야 합니다.
8. 호남이 주목받는 이유. 땅만 고르는 게 아니라, 에너지와 건축을 함께 설계하기 때문입니다.

‘호남이 유일한 정답’이라는 입지 타당성 판정이 아니라, **호남을 검토할 이유에 관한 해설·제안**이다. 구체적 사례는 전남이며 전북·광주를 포함한 호남 전체가 동일한 전력망·용수 조건이라는 뜻이 아니다. 재생에너지가 많아도 상시 전력 공급이 보장되지 않으며, 계통 연결·냉각 및 용수·통신망을 후보 부지별로 검증해야 한다. 폐열 활용·저렴한 전기요금·싼 땅값·신규 사업의 가동 여부는 검증하지 않아 확정적 장점으로 넣지 않았다. 발전·저장·캠퍼스 도해는 연결 개념을 보여주며 실제 사업 배치나 전력 공급 계약을 나타내지 않는다.

## 재현

애니메이션 기능이 포함된 commerce-automation-kit checkout과 설치된 npm 의존성, ffmpeg/ffprobe, 기존 Cloudflare runner 인증이 필요하다.

```sh
CAK_ENGINE_ROOT=/path/to/commerce-automation-kit node docs/videos/20260929-honam-datacenter/produce.mjs
```

기본 제작 캐시는 `/private/tmp/cak-honam-datacenter-20260929`이며 `HONAM_VIDEO_CACHE`로 바꿀 수 있다. 완료된 음성을 캐시하여 같은 대본으로 다시 렌더할 때 중복 생성하지 않는다. 새로운 음성 생성에는 ElevenLabs 사용량이 발생한다. 영상 시간은 음성 실측 후 총 1800프레임으로 배분하며, 대사를 잘라내거나 임의로 빠르게 재생하지 않는다. 음성이 60초를 넘으면 렌더를 중단하고 대본을 줄이도록 한다.
