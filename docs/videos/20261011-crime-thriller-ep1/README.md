## 제작 및 검증

대본 검수에서 ‘실종’만으로 사칭을 단정한 초안을 수정했고, 외부 열쇠 → 내부 썸턴으로 시점을 분리했다. 최종 `story.json`과 `review.json`의 정확한 검토 조합을 TTS 전에 검증했다.

Blender 미리보기에서 카메라가 인물 몸 안으로 들어간 문제, 신분증 과노출, 열쇠 꼬리표 잘림, 휴대전화 높이를 수정했다. 손이 의자를 밀고, 열쇠가 들어가며, 내부 썸턴·문·체인이 움직인다. 실내의 따뜻한 빛과 복도의 차가운 빛을 구분했다. 헤더는 민트/흰색, 자막은 Pretendard SemiBold와 둥근 차콜 배경이다.

디스크 공간 부족으로 첫 렌더가 중단됐다. 본인 작업의 미리보기·전사용 복사본 32.12MiB만 정리하고 검토 모음을 남겼다. 대용량 음성 인식과 렌더를 순차 실행하고, 반복 PNG 저장 대신 Blender에서 MP4로 직접 인코딩하여 전체 렌더를 완료했다. iCloud가 로컬 디스크를 사용하지 않는다고 가정하지 않는다.

## 재현 소스

- `produce.mjs`: 검토 대본 확인 → 기존 Cloudflare 브로커에서 메모리로 인증 → 공식 ElevenLabs API. 중복 과금 방지 영수증, 자동 유료 재시도 없음.
- `scene.py`: 자체 Blender 공간·소품·카메라·애니메이션. 최종 EEVEE / 16 samples / 100% 해상도. 장면별 MP4와 SHA·프레임 수·렌더 설정 기록. 타인 영상 다운로드나 재사용 없음.
- `finish.py`: 실제 음성 길이 반영, 대사를 자르지 않는 타임라인, 직접 합성한 효과음, 자막·헤더, H.264/AAC 조립 및 디코드·오디오·자막 검증.

- `preflight.json`: 당시 Higgsfield 부족 상태는 이력으로 보존하고, 이번 편의 Blender 예외 승인을 별도로 기록했다.
