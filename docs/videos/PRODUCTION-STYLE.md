# 영상 제작 기준

## 이후 신규 영상의 공간·연출 기준 — 2026-10-02

사용자 지시: “기존영상은 수정하지 말고 이후영상들부터 적용되게”. 다음 신규 제작부터 아래 기준을 적용한다. 기존 유리기판·TGV 롱폼/숏폼 등 완성 영상은 수정·덮어쓰기·재렌더링하지 않는다. 이 지시만으로 새 영상 제작이나 추가 유료 생성을 시작하지 않는다.

목표는 대상이 놓인 공간과 실제 작동 과정을 따라가며 원리를 발견하는 입체적인 설명 영상이다. 최근 TGV의 빈 배경·단순 부품·유사한 관찰 각도가 반복되는 구성을 다음 편의 기본 템플릿으로 재사용하지 않는다.

- **공간과 규모:** 공장, 장비 내부, 도시, 해저 등 주제에 맞는 환경 안에 대상을 배치한다. 주변 설비와 크기를 비교할 수 있는 사물로 규모를 전달한다. 단순 단면 모형은 필요한 설명 구간에 한해 사용한다.
- **재질과 조명:** 유리의 투과·굴절, 금속의 반사·거칠기, 표면의 세부 구조를 표현한다. 대상과 배경의 명도·색 대비를 확보하고 접촉 그림자와 깊이감을 살린다. Higgsfield 도입부와 본문의 재질·조명·색감을 연결한다.
- **카메라와 동작:** 전체 환경 → 대상 접근 → 내부/단면 확대 → 작동 과정 → 결과의 흐름으로 장면을 설계한다. 같은 거리의 느린 회전이나 부품의 반복 이동으로 대본 길이를 채우지 않는다. 내레이션의 원인·변화·결과가 실제 화면 동작과 맞아야 한다.
- **쇼츠 구도:** 9:16 전체 화면을 장면으로 사용한다. 가운데 작은 가로 영상과 위아래 넓은 여백, 상시 고정 제목으로 화면을 분할하는 구성을 기본값으로 쓰지 않는다. 롱폼 자산 재활용 시에도 핵심 구조가 잘리지 않도록 세로 구도를 별도로 설계한다. 추가 유료 생성이 필요한 경우 기존 예산·승인 범위를 따른다.
- **자막:** 영상 위에 짧고 읽기 쉬운 자막을 배치하고 핵심 동작을 가리지 않는다. 글자 외곽선·그림자로 대비를 확보하며 제목·라벨·자막을 동시에 과하게 노출하지 않는다. 사용자가 선택한 음성·속도는 별도 요청 없이 변경하지 않는다.
- **제작 검증:** 신규 편의 대표 구간을 먼저 렌더해 공간감, 재질, 카메라 변화, 설명과 동작 일치, 모바일 자막 가독성을 확인한 뒤 전체 제작에 확장한다. 파일 디코딩·음성 길이 검사만으로 시각적 품질을 통과 처리하지 않는다. 이 검증은 기존 영상 재작업 지시가 아니다.

비교 근거(2026-10-02 화면 확인): [신비한 건축사전](https://www.youtube.com/channel/UCeEM8XgdgUyaWE1Z6_5sHbQ)의 [제주 해저케이블 롱폼](https://www.youtube.com/watch?v=sqs5Ra5NDaI)에서 공장 내부·전선 확대·해저 공간, [3D 프린팅 주택 쇼츠](https://www.youtube.com/shorts/vjSGza3Aeq0)에서 세로 전체 화면 구도를 확인했다. 참고 대상은 공간 구성과 설명 연출이며 원본 영상·대본을 복제하거나 다운로드해 재사용하지 않는다. 해당 채널의 제작 도구는 미확인이다.

이 절은 제작 세션이 따를 지침이다. 웹 제작실 런타임 구현·운영 배포나 이미 열린 모든 세션의 수신 확인을 의미하지 않는다. 아래 Higgsfield 도입부 및 예산 기준은 계속 적용한다.

## 도입부: Higgsfield 필수

사용자 지시(2026-10-01): “처음 부분은 무조건 힉스필드로 만들자”.

- 첫 도입 장면은 주제의 궁금증을 실제처럼 보여주는 Higgsfield 영상으로 만든다. 사용자 승인(2026-10-01)에 따라 기본은 6초 한 컷이며 길이는 별도 사용자 요청에 따른다.
- 내부 구조·원리·문제 발생과 해결은 자체 코드 기반 3D로 이어간다. 부품을 단순 반복 이동시키는 대신 내레이션에 맞는 조립, 흐름, 변화, 결과를 순서대로 보여준다.
- 생성 영상과 3D의 색감·재질·광원 방향을 맞춘다. 개념 모형과 AI 재현은 실제 촬영·실측과 구분한다.
- 크레딧이나 인증 문제로 도입부를 만들지 못하면 이를 미완료로 알린다. Higgsfield 대신 다른 제작 방식으로 조용히 대체하지 않는다. 별도 승인이 없는 결제·요금제 변경은 하지 않는다.
- 제작 지침으로 저장한 상태다. 기존 완성본 재렌더링, 웹 제작실의 강제 적용 코드 또는 운영 배포 완료를 뜻하지 않는다.

## 현재 승인된 제작 예산 — 2026-10-01

- 사용자가 Pro 결제와 월 1,200크레딧을 확인했다. 이는 사용자 제공 구독량이며 실제 계정의 현재 잔액을 조회한 결과는 아니다.
- 도입부 6초 한 컷에 Higgsfield를 집중하고, 본문은 설명에 맞는 자체 3D로 제작한다. 단순 반복 대신 문제 발생 → 변화 → 결과를 내레이션과 맞춘다.
- 이 기준 적용 후 처음 제작하는 3편의 실제 사용량과 재생성 횟수를 기록하고 월 제작 가능량을 다시 계산한다. 이 합의만으로 새 영상 3편을 일괄 생성하거나 기존 완성본을 재렌더링하지 않는다.
- 기존 실측인 6초당 54크레딧을 적용하면 한 번에 채택 시 최대 22편(1,188크레딧), 편당 평균 두 번 생성 시 11편(1,188크레딧)이다. 이미지·본문 추가 컷·업스케일 등 다른 사용량은 제외한 계산이다.
- 매 생성 전 공식 비용과 확인 가능한 잔액을 확인한다. 접수 결과가 불명확하면 작업 이력부터 확인하고 중복 제출하지 않는다. 추가 결제·요금제 변경은 별도 승인 없이 하지 않는다.

## 기본 영상 스타일: 웹툰 — 2026-10-05 사용자 지시

- 이후 영상은 주제·롱폼·숏폼과 관계없이 **웹툰 기반**을 기본으로 한다. 사용자가 실사·3D 등 다른 스타일을 지정하면 해당 요청이 우선한다.
