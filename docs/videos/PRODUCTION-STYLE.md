# 영상 제작 기준 — 2026-10-04

사용자 채널 피드백을 반영한 앞으로의 제작 기준. 제공된 Analytics 수치는 사용자의 보고이며 직접 조회한 검증 결과가 아니다. 계속 시청함 70%, APV 80%, CTR 4~5%는 실험 목표이고 노출 확대나 2,000조회 보장 조건이 아니다. 표본과 노출 경로를 구분해 비교한다.

- 이 사용자의 채널은 당분간 AI 신기술·반도체를 우선한다. 이미 요청한 건축은 완료한다. 심리학·광고 영상을 삭제하거나 플랫폼 전체의 카테고리를 제한하지 않는다.
- 쇼츠 기본 45초, 보통 30~45초. 사용자가 선택한 길이는 우선한다. 0초부터 핵심 대상과 3초간 짧은 질문 자막. 인사·로고·긴 예고 생략. 핵심 원리·발견·완결된 답을 보존하고 반복과 배경을 줄인다. 문장을 자르거나 추가 배속으로 맞추지 않는다. 루프는 답을 한 뒤 처음 대상을 새롭게 보게 하는 방식이다.
- 롱폼은 설명의 깊이를 유지한다. 첫 15초에 구체적 질문과 작은 답·시각적 결과를 먼저 보여준다. 배경과 용어 정의는 필요한 시점에 설명한다.
- 제목은 쉬운 질문을 앞에, TGV·HBM 등 검색어를 뒤에 둔다. 썸네일은 대상 하나·명확한 대비·짧은 질문. 확인되지 않은 기업의 채택이나 '10배' 수치를 클릭 유도 문구로 만들지 않는다.
- 해시태그는 실제 주제 관련 항목만 쓴다. 반도체 영상에 automobile 등 무관한 태그를 넣지 않는다. 개수보다 관련성을 우선한다.
- 쇼츠·본편을 한 쌍으로 기획하고 본편 URL을 기록한다. 업로드 후 YouTube Studio에서 같은 채널의 공개·일부 공개 본편을 관련 동영상으로 선택한다. 고급 기능 접근이 필요하다. 설명·댓글 URL은 쇼츠에서 클릭되지 않아 대체 수단이 아니다. 실제 저장 확인 전에 연결 완료로 보고하지 않는다.
- 첫 6~8초는 주제에 맞는 Higgsfield 도입을 사용하고 이미 생성한 자산을 재사용한다. 사용자 Pro 1,200크레딧 예산을 고려한다. 본문은 구체적인 원인과 결과를 보여주는 자체 제작 영상·코드 모션과 조합한다. 추가 결제·임의 재생성은 하지 않는다.
- 같은 전체 구도를 계속 반복하지 않는다. 전체 위치 → 설명할 부위 → 실제 변화 → 결과로 구도를 연결한다. 재질·명도·조명으로 대상과 배경을 분리하고 개념도와 실측을 구분한다.

## 과도한 압축 방지 — 다음 영상부터

제작 전 [설명 깊이·쇼츠 검토](EXPLANATION-DEPTH.md)를 적용한다. 웹툰을 기본으로 하되 스타일 재제작/자산 재사용도 대본 검토를 생략하는 근거가 아니다. 롱폼은 왜·과정·예시·영향/한계, 숏폼은 한 질문에 대한 완결된 설명을 남긴다. 별도 대본 검토 실패 시 TTS·미디어 생성으로 넘어가지 않는다. 첫 1~2초 후킹과 기본 30~45초 실험은 설명 생략·결말 절단·배속 추가를 허용하지 않는다. 조회수/시청률 목표는 노출 보장 기준이 아니다. 기존 완성 영상은 이번 변경으로 재생성하지 않는다.
