# 선택형 설명 애니메이션

2026-09-29. 수동 기획과 자동 트렌드 검색에서 일반 영상 / 손그림 설명 애니메이션을 선택한다. 선택은 프로젝트의 `brief.productionStyle: "animation"`으로 저장하며 이전 프로젝트의 동작은 유지한다.

## 생성과 편집

연결된 Codex 또는 Claude가 기존 구독 시나리오 경로로 대본과 `scene.animation`을 작성한다. AI는 장면 제목, 2~4개 개체의 아이콘·문구·움직임, 순서/대비/순환 구성을 반환한다. 서버가 스키마를 검사하고 고정 SVG 렌더러 → resvg → FFmpeg로 30fps H.264 MP4를 만든다. AI가 반환한 임의 코드·SVG·URL은 실행하지 않는다. 이 구현은 Remotion을 사용하지 않는다.

지원 개체는 사람·뇌·하트·시계·전화기·책·구름·집·나무·별, 움직임은 등장·부유·강조·흔들림이다. 참고 영상의 자유로운 캐릭터 애니메이션이나 종이 콜라주를 완전히 재현하는 구현은 아니다. 첫 버전은 개념 설명에 사용하는 손그림 도식이다.

- 기획 선택 → AI 시나리오 → 대본/화면 제목/개체 문구 검수 → 장면 생성 → 기존 편집·목소리·배경음·자막 → 최종 렌더 → 별도 발행 검수.
- 애니메이션 장면은 `kind: video`이며 힉스필드/Google 미디어 생성 API를 호출하지 않는다. 생성 영상과 최종 렌더는 기존 저장소를 사용한다.
- 장면 제목·문구·대사·길이·구성 변경 시 해당 AI 미디어를 무효화한다. 생성된 장면은 다시 요청해도 재사용한다.
- 자동 제작은 검수 후 장면 생성, 실제 음성 길이 확인, 편집 구성, 렌더 순서다. 짧은 애니메이션은 마지막 프레임을 유지한다. 발행 사람 게이트는 유지한다.
- 힉스필드 영상 크레딧은 사용하지 않는다. LLM 구독 사용량, 기존 TTS 사용료, 렌더 서버 자원은 별개다.

## 검증

`node --test apps/shopshorts/test/studio-animation.test.mjs`는 기획/추천/시나리오 전달, 입력 검증, 수정 시 무효화, 자동 제작의 서버 저장값 사용, 실제 MP4 생성·프레임 변화·재시도·외부 영상 API 미호출을 검증한다.

`PLAYWRIGHT_CHANNEL=chrome node apps/shopshorts/test/animation-browser.mjs`는 독립 로컬 서버에서 실제 UI/API/제작 워커를 사용한다. 선택 저장, 화면 문구 수정, 미디어 재생, 자막 포함 최종 렌더, 자동 화면 선택, 모바일 넘침을 확인한다. 대본은 명시적인 합성 fixture이며 실제 Codex/Claude·유료 TTS·업로드 호출은 수행하지 않는다. 로그의 `dir`에 화면과 6초 무음 샘플을 남긴다.

전체 회귀: `cd apps/shopshorts && node --test --test-reporter=dot test/*.test.mjs`.

2026-09-29 실행 결과: 애니메이션 테스트 5개, 관련 회귀 54개, Shopshorts 전체 회귀 및 Chrome E2E 통과. [6초 무음 샘플](qa/animation-sample.mp4)은 합성 대본 fixture로 생성한 1080×1920, 30fps 영상이며 첫 장면의 자막 합성을 포함한다. 실제 구독 LLM의 출력 품질·유료 음성 실생성과 운영 배포는 검증 범위에 포함하지 않는다.

## 운영 반영

이 변경은 구현 브랜치용이다. PR 승인·머지와 운영 배포를 별도로 확인한다. Pages에는 UI/검증 코드, 계정 실행기에는 새 시나리오 지침, 제작 워커에는 `@resvg/resvg-js` 및 렌더러가 필요하다. 워커에 `npm ci`와 FFmpeg, 저장소에 포함된 NanumGothic 폰트가 필요하며 heartbeat의 `animation: true`를 확인한다. **Pages만 배포해서는 완료되지 않는다.** 운영에 적용하려면 실행기를 먼저 갱신하고 Pages를 반영한 뒤 연결 계정으로 실제 대본 생성부터 재검증한다.

Claude Code로 동영상을 만드는 일반적인 방식에 대한 참고: [Remotion 공식 Claude Code 안내](https://convert.remotion.dev/docs/ai/claude-code-plugin). 사용자가 제공한 영상이 이 도구로 제작됐다는 증거는 아니다.
