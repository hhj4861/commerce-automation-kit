# AI 계정 연결 화면 개선 — 2026-09-20

## 변경

- 480px 계정 선택 팝업: Codex·Claude 전체 행을 선택 버튼으로 사용한다. 제공사 이름과 구독 종류만 남기고, 비활성 진행 버튼·상시 새로고침·반복 설명을 제거했다.
- 선택 후에는 해당 제공사의 인증 단계만 표시한다. Codex는 코드 확인 → 공식 화면 입력, Claude는 공식 로그인 → 일회용 코드 붙여넣기 순서다.
- 연결된 계정은 계정명·상태·해제·완료만 보여 준다. 오류/오프라인일 때만 다시 확인 버튼을 노출한다.
- 주기적 상태 조회 중 인증 코드, 선택 범위, 버튼/링크 포커스를 유지한다. 390px 모바일에서 긴 오류가 있어도 가로 넘침 없이 동작한다.
- Claude CLI 원문을 노출하지 않고 로그인, 인증, 키체인, 저장, 한도, 네트워크, 시간 초과, 설치, 결과 형식 실패를 고정된 안내 문구로 구분한다. 워커 로그에는 제공사·작업 종류·허용된 오류 코드만 기록한다.

## 운영 오류 조사 범위

운영 저장소를 읽기 전용으로 확인했을 때 Claude 작업은 `kind=connect`, `state=failed`, `connected=false`였고 인증 정보가 저장되지 않았다. 추천 생성 이전의 연결 실패다. 기존 워커는 상세 원인을 버리고 일반 안내만 저장했으며 로그도 비어 있었다. **기존 실패의 정확한 원인이나 해결 여부는 확정하지 않았다.** 변경 반영 후 사용자의 공식 OAuth 인증 재시도로 확인해야 한다.

Mac 실행기에서는 공식 Claude CLI가 `CLAUDE_CONFIG_DIR`별 키체인 항목을 사용한다. 앱이 이 격리된 인증 정보를 읽어 Cloudflare 암호화 저장소로 전달하고 작업 후 임시 항목을 정리한다. 따라서 키체인 승인은 Cloudflare 로그인 절차가 아니라 Mac의 Claude 인증 저장소 접근이다. 이 변경은 키체인 접근을 제거하거나 권한을 우회하지 않는다. Linux 실행기는 공식 CLI의 권한 0600 파일 저장소를 이용한다.

근거: [Claude 공식 인증 저장소 설명](https://code.claude.com/docs/en/authentication#credential-management). 조사 시 로컬 공식 CLI 버전은 2.1.278이다. [공식 환경변수](https://code.claude.com/docs/en/env-vars)에 자동화용 OAuth 환경변수도 있으나, 갱신·회수·격리 동작 검증 없이 현재 연결 방식을 임의 교체하지 않았다.
