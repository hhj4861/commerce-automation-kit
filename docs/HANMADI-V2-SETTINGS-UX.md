# Hanmadi 2.0 설정 화면 UX 보완

2026-09-29. 승인 시안: 프로젝트 `docs/hanmadi-2.0-mockup/index.html`의 설정 및 내 AI 연결 화면.

## 변경

- 설정과 내 AI 연결을 작은 대화상자에서 앱 내부 화면으로 전환했다. 상단 뒤로 가기와 하단 4개 메뉴를 유지한다.
- 설정에 4개 언어, 하루 5·10·15분, 실제 교육과정의 4단계 말하기 카드를 제공한다. 계정 저장 상태로 선택 표시를 갱신한다.
- 레벨 체크 전에도 설정 항목을 표시하고, 시간·단계는 체크 완료 후 조절하도록 안내한다. 번역과 내 표현은 먼저 사용할 수 있다. AI 대화는 레벨 체크 안내를 제공한다.
- 번역 자동 학습 스위치, 발음 도움, AI 연결, 학습 표현 확인·삭제, 데이터 안내, 기존 수업과 로그아웃을 제공한다. 관리자 링크는 소유자에게만 표시한다.
- 언어 저장 실패 시 선택 표시와 브라우저의 언어 설정을 이전 값으로 되돌린다.
- 내 AI 화면에서 현재 AI, 연결 관리, 모델 선택 카드와 대화 시작을 제공한다. 기본 Gemini, 실제 Codex 계정 연결, Claude API 키 연결을 유지한다. Claude 구독 OAuth를 지원한다고 표시하지 않는다.
- 설정에서 AI 화면으로 이동한 경우 뒤로 가면 설정으로 돌아온다. 하단 메뉴는 보조 화면을 닫고 해당 화면을 연다. 레벨 안내 대화상자를 닫는 Escape가 설정 화면까지 닫지 않도록 한다.
- 긴 이름·모델명, 작은 화면의 행·입력·대화상자 제목에서 넘침을 방지한다.

## 검증

- `npm run test:v2`: 전체 사용자 흐름 통과. 실제 로컬 앱·저장 API를 사용하며 LLM·음성·계정 연결 공급자는 fixture다. 실제 공급자 응답 품질 검증으로 해석하지 않는다.
- 설정: 레벨 체크 전 진입, 번역 접근, 시간·단계·자동 학습 저장, 새로고침 후 유지, 언어 저장 실패 복구, 모델 카드 선택 후 실제 요청 모델 확인, 설정↔AI 이동, 로그아웃 검증.
- 320×640, 360×800, 390×844, 768×500, 1440×900에서 설정·AI 화면 가로 넘침 없음, 상단·본문·하단 메뉴 겹침 없음. 기존 스터디 360/390/768/1440 검증도 통과.
- `npm run lint`: 오류 없음. 기존 비관련 파일의 unused-variable 경고 4개 유지.
- `npm run build`: 프로덕션 빌드 확인.
- 브라우저 캡처를 직접 확인: [설정 상단](hanmadi-v2-e2e/settings.png), [설정 하단](hanmadi-v2-e2e/settings-bottom.png), [내 AI](hanmadi-v2-e2e/ai-settings.png).
