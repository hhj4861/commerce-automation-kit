# Jev 플랫폼 적용 검토 요약

2026-09-30 | 코드·기존 배포 기록 및 공식 문서 검토 | Jev 실호출·운영 적용 없음

**Festa의 AI 인터뷰 판단부터 소규모 비교 실험을 권장합니다. 기존 LiteLLM은 유지하고, Jev는 선택·분류·검사에 한정해 사용합니다.**

**역할과 적용 범위**

Jev는 정해진 후보 선택·점수 평가·조건 판단을 맡고, 기존 LLM은 질문·대본·번역을 작성합니다. 영상·음성을 직접 분석하지 않습니다. 날짜·예산·권한 계산과 사람의 게시 승인은 기존 코드·절차가 담당합니다. [1][2]

**비용과 현재 연결 상태**

공식 입력 가격은 100만 토큰당 $0.042, 출력은 무료입니다. 요청당 총입력 2,000토큰 가정 시 1만 회 $0.84, 100~200건 실험은 약 $0.01~0.02입니다. 기존 LLM·재시도·서버 비용과 최소 충전액은 별도입니다. 사용자 콘솔은 크레딧 부족으로 키 발급이 막힌 상태이며, 충전·키 발급·연동 완료는 확인되지 않았습니다. [1]

**권장 실행 순서**

1) Billing 최소 충전 조건 확인 후 키 발급 → 서버 비밀 설정에 보관. 2) Festa 한국어 사례 100~200건으로 기존 LLM과 Jev를 비교하되 운영 결과는 유지. 3) 다음 주제 정확도·반복 질문률·응답 지연·총비용을 비교해 적용 여부 결정. 불확실하거나 실패하면 기존 방식으로 처리합니다.

**판단의 한계**

기대효과는 코드 구조에 근거한 가설이며 실측 수익·절감률이 아닙니다. 한국어·일본어·태국어 성능은 별도 검증해야 하고, confidence는 정답률 보장이 아닙니다. Festa의 자유문장 knownFacts는 단순 대체할 수 없어 답변 원문·근거 번호 전달이 필요합니다. 한마디의 9월 30일 점검 기록상 추가 게시 자료는 0개였으므로 자료 확보가 우선입니다. [1][2][3]
