## 실제 적용

- 원본 이름 BetterrShop 유지. 한국어 번역 이름 BetterShopp → BetterrShop 통일.
- 핸들 @flusp-b9p 유지.
- 영어(영국)로 지정돼 있던 원본 소개에 영문 소개를 저장. 별도의 한국어 소개를 보존하여 두 언어가 함께 저장된 화면 확인.
- 소개는 심리학·건축학 애니메이션 지식 채널로 정리. 기존 쿠팡 제휴 고지를 두 언어 모두 유지.
- 홈 탭 OFF → ON, 기존 섹션 유지.
- 쇼핑 해시태그 24개 → 주제 키워드 18개: BetterrShop, BetterShopp, 심리학, 생활심리, 인간관계, 감정, 습관, 부모자녀관계, 대화법, 시니어심리, 건축학, 건축이야기, 도시, 공간, 인프라, 교양, 지식애니메이션, 정보영상.
- 업로드 기본 설명: 채널 소개 및 대상 채널 링크 추가.
- 주식·투자·쇼핑 기본 태그 20개 → BetterrShop, BetterShopp, 지식애니메이션, 교양. 이전 표기 검색을 위한 BetterShopp 태그는 유지.
- 업로드 카테고리 노하우/스타일 → 교육.

## 검증과 적용 범위

게시 완료 메시지와 비활성 게시 버튼 확인. 설정을 다시 열어 주제 키워드·기본 설명·태그·교육·한국어·홈 활성화 값 확인. 영어 게시 후 번역 창에서 한국어 보존 및 양쪽 이름 통일 확인. 증거: [설정 화면](20260929-betterrshop-settings.png).

채널 설정은 실제 반영됨. 업로드 기본값은 브라우저 업로드용이며 기존 영상 및 API 업로드에 소급 적용되지 않는다. 기존 영상의 영어 제목·설명·자막·더빙 생성/검수/게시, 새 영상 업로드, 채널 이전, 수익화 신청은 수행하지 않았다. 영어권 제공을 위해서는 영상별 번역 제목·설명·자막과 오디오를 별도로 확인해야 한다. 화면에 구워 넣은 한국어 텍스트는 더빙으로 번역되지 않으므로 언어별 렌더 또는 텍스트가 적은 원본을 권장한다.

자동 승인 검토가 원본 설명의 영어 교체를 한국어 손실 위험으로 일차 거부했다. 실제 번역 창에서 원본 언어 영어(영국) 및 별도 한국어 번역의 존재를 확인한 후, 한국어를 보존하는 변경임을 입증하여 영문 원본 저장을 진행했다. 권한 우회는 하지 않았다.
