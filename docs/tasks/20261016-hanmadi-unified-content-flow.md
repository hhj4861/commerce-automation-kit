- 완료: 공통 영상 검색·주소 등록·용도 선택, 저장 원문 전달, 기존 음악 수집함 연결, 검수에서 생성/게시, 운영에서는 게시 자료만 관리. 회화·음악 E2E·기존 회귀·타입/lint/build 통과, 본인 커밋/push/PR.
- 설계: 기존 파랑 #3157d5·배경 #f5f7fc·본문 #243247·경계 #dbe2ef 유지. Pretendard/system 글꼴. 좌측 세 단계와 현재 작업 본문, 모바일 같은 순서. 장식보다 콘텐츠의 출처/용도/상태/다음 행동을 표시. 별도 음악 수집 시작점을 없애고 기존 자료는 준비 단계에서 연결.
- 상태: 공통 수집·원문 전달과 단계 분리 구현. 단위 290개·타입·변경 lint 통과, 원문 관리 네 언어 실제 Next/API/저장소 E2E 통과. 음악 수집/원문/검수/게시/네 언어 학습, 음악 JEV 재시도 및 전체 V2 E2E 통과. 최종 명칭·영역 이동 화면 및 production build 통과. 코드 검토와 PR 준비 중. OpenRig refocus trace는 topology/work 노드가 미해결이며 경로를 지어내지 않았다. 사용자 요청·현재 소스·기존 QA를 직접 읽어 범위를 확정.
- 검증: 심볼릭 링크 의존성은 Turbopack이 거부해 lockfile 정상 설치로 해결. Playwright 전용 브라우저 캐시가 없어 설치된 Chrome의 별도 headless 프로필 사용. 파일 연결 JSX 오류는 함수로 정리 후 타입/원문 E2E 통과. 음악 fixture의 전용 검색 기대값은 통합 일반 검색에 맞춰 조정했으며, 실패를 통과로 보고하지 않음. 운영 머지/배포는 이 새 PR에 대한 별도 승인 전까지 수행하지 않음.
