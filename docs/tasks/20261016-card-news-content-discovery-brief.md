# 카드뉴스 콘텐츠 방향 정정과 새 게시 후보 — 2026-10-16

## 사용자 요구와 현재 적용 범위

사용자는 작은 버그 수정·릴리스 요약보다 최신 플러그인, 오늘/이번 주 관심을 받는 플러그인,
AI Agent의 실제 활용법, 새로 공개된 오픈소스를 발견하는 콘텐츠를 원한다.
각 카드는 해당 자료의 정확한 원문 URL과 1:1로 대응한다. 원문을 카드 화면에 표시하는 것과
Instagram 영상 안에서 클릭할 수 있는 기능은 구분한다.

게시 전 내용을 먼저 보여달라는 지시가 유지된다. 기존 무음 릴스는 보류한다.
현재 자동화의 고정 릴리스 소스·편집 프롬프트·영상은 이 문서 저장만으로 변경되지 않는다.
운영 모드도 render이며 공개 게시 및 자동 업로드 활성화를 하지 않았다.

## 편집 기준

- 세 축: 플러그인 발견 / Agent 활용법 / 신규 오픈소스. 가치 있는 내용이 없으면 개수를 채우지 않는다.
- 카드마다 어떤 도구인지, 왜 지금 볼 만한지, 실제로 해볼 한 가지, 이용 조건, 정확한 원문 URL을 연결한다.
- 설치·실사용을 하지 않은 후보는 문서 확인으로 표시하고 실사용 후기나 성능 개선을 주장하지 않는다.
- ‘인기’에는 측정 기간·시각·지표·비교 모집단을 표시한다. GitHub 별은 저장소 관심 지표이며 설치 수가 아니다.
- ‘최신’은 최초 공개/저장소 생성/최근 릴리스/활용 가이드 발행을 구분한다. 최근 커밋만으로 새 제품이라 하지 않는다.
- 공식 GitHub API, 발행자의 문서·공식 가이드로 사실을 검증한다. 순위 수집을 위해 화면 크롤링이나 비공식 API로 대체하지 않는다.

## 새 게시안 초안

### 1. 주목 플러그인 — Superpowers

- 제목: **AI에게 바로 코딩시키기 전에, 설계와 테스트부터 잡아주는 플러그인**
- 내용: 요구사항을 정리하고 설계를 검토한 뒤 구현 계획·테스트·리뷰 순서로 진행하도록 안내하는 스킬 묶음이다.
- 써볼 예: 작은 기능 하나에 요구사항 정리 → 계획 → 테스트 순서를 적용해 기존 작업 방식과 비교한다. 성공률 향상 수치는 제시하지 않는다.
- 지금 볼 이유: 공식 API의 이번 주 신규 별 3,239개. 신제품이라는 뜻은 아니다.
- 원문: https://github.com/obra/superpowers
- 상태: 문서·관심 지표 확인. 이 작업에서는 설치하거나 실행하지 않았다.

### 2. 실전 Agent 활용 — 고친 화면을 브라우저에서도 확인시키기

- 제목: **‘수정했습니다’에서 끝내지 말고, Agent에게 화면 확인까지 맡기기**
- 내용: 저장소 지침으로 프로젝트 규칙을 전달하고, 스킬로 검사 절차를 정리하고, Playwright MCP로 브라우저 조작·동작 확인을 연결하는 방법이다.
- 써볼 예: 수정한 버튼을 브라우저에서 눌러 기대 화면이 나오는지 확인하도록 요청한다. 문서 기반 활용 예이며 실측 결과로 제시하지 않는다.
- 최신 근거: GitHub 공식 활용 가이드 발행 2026-10-12. 해당 기능 자체가 이날 처음 출시됐다고 주장하지 않는다.
- 원문: https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/

### 3. 신규 오픈소스 발견 — Talorys

- 제목: **기억하고 할 일을 챙기는 개인 AI 비서, 내 클라우드에서 돌린다면?**
- 내용: 본인 Cloudflare 계정에서 대화·기억·할 일·메모·예약 알림을 운영하는 개인용 오픈소스다.
- 써볼 예: 내일 할 일을 등록하고 예약 알림이 오는 흐름을 확인한다. 배포·실사용은 아직 하지 않았다.
- 신규 근거: GitHub API 저장소 생성 시각 2026-10-10T09:46:56Z. 최초 공개일/정식 출시일과 같다고 단정하지 않는다.
- 조건: MIT, Cloudflare 계정 필요. 무료 한도가 있으며 ‘무제한 무료’로 소개하지 않는다.
- 원문: https://github.com/rociiu/talorys
