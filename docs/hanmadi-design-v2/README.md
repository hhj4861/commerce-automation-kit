## 제작 전 디자인 계획

- 기본색 6개: 브랜드 `#3157d5`, 본문 `#192a4b`, 보조 `#69758b`, 바탕 `#f5f7fc`, 면 `#ffffff`, 경계 `#e1e6ef`. 성공/저장 피드백만 차분한 초록 사용.
- 글꼴: 한국어 시스템 글꼴(Apple SD Gothic Neo/Noto Sans KR), 일본어는 플랫폼 기본 일본어 글꼴. 제목 24–30, 학습 문장 23–28, 본문 15–16, 보조 13–14px. 긴 외국어는 자연스럽게 줄바꿈.
- 모바일: 4개 하단 메뉴, 위는 짧은 언어/상황 선택, 가운데 현재 과업, 대화 입력은 하단 고정 영역. 번역은 입력과 결과를 연속 배치. 음악은 단계 선택과 현재 한 줄만 집중 표시.
- PC: 왼쪽 탐색, 가운데 대화/학습, 오른쪽 참고 표현 또는 전체 가사. 입력은 본문과 별도 행을 차지해 겹치지 않게 한다.
- 원칙: 생성 서비스의 기술 정보보다 사용자의 말과 학습 행동을 강조. 저장·재시도·선택·포커스 상태를 같은 기준으로 표현. 주요 버튼 최소 44px.

사전 검토: 커다란 소개 카드와 진행 숫자를 장식으로 반복하지 않는다. 한마디의 특징인 ‘학습한 표현을 실제 대화에 바로 사용’하는 흐름을 화면 중심에 둔다. 음악의 배경 그림 대신 실제 조작 가능한 현재 줄과 작은 플레이어를 사용한다. 기존 브랜드·기능명은 유지하고 입력·과업 배치를 바꾼다.

## 파일

- `index.html`: 모바일/PC 반응형 클릭 시안. 로컬 파일로 바로 열 수 있다.
- `overview.html`: AI 대화·번역·음악을 한눈에 비교하는 모바일 보드.
- `design.css`, `prototype.js`: 위 시안의 표시와 예시 상호작용만 담당. API·녹음·실제 재생·기기 영구 저장 없음.
- `hanmadi-mobile.drawio`: 주요 3개 화면의 편집 가능한 구조 설계본. HTML 시안이 상세한 시각 검토 기준이다.

## 확인할 흐름

1. AI 대화에서 문장을 입력 → 스터디 → AI 대화: 미전송 초안이 이 페이지를 연 동안 유지된다. 새로고침하면 초기 예시로 돌아간다.
2. 번역: ‘직접 입력/말하기’ 전환, 번역 예시 확인, 표현 저장 피드백.
3. 음악: 듣기/따라하기/활용/복습 전환, 단어 뜻 선택, 전체 가사, 다음 줄, 배운 표현을 대화 입력으로 연결.
4. 스터디·단어·보관함의 연결과 선택 상태 확인.

운영의 초안 삭제·입력 배치·음악 동선이 이 파일을 만든 것만으로 수정된 것은 아니다. 시안 검토 후 실제 앱 구현에서 별도 적용·검증한다.

## 검증 상태

2026-10-15 검토 완료. 시안 파일만 검증했으며 운영 앱 검증 결과가 아니다.

- Chrome에서 390×844, 320×568, 1440×900 화면을 확인했다. 가로 넘침 없음. 모바일 대화 입력창은 하단 메뉴와 분리되어 보인다(320px 화면: 입력 y437–483, 메뉴 시작 y498). 번역 원문 입력도 첫 화면에 보인다(y437까지, 본문 끝 y498).
- 대화 입력 → 스터디 → 대화에서 미전송 문장 유지, 번역의 직접 입력/말하기 전환, 음악 단어 정답 피드백, 다음 가사와 연습 단어의 동시 변경, 음악 표현의 대화 입력 연결을 직접 클릭해 확인했다.
- PC에서는 왼쪽 탐색·본문·오른쪽 참고 표현이 분리된다. 대화 입력 끝 y846으로 900px 화면 안에 보이며 본문과 참고 패널 경계가 x1155에서 일치한다.
- HTML 모바일 비교 보드·스터디·PC 캡처와 draw.io SVG 렌더를 시각 검토했다. JS 구문 검사, Git 공백 검사, native XML/SVG 파싱을 통과했다.
- 실제 모바일 키보드·VoiceOver·Flutter 런타임은 이번 시안 범위에서 검증하지 않았다. 녹음·음악 재생·AI 응답·저장은 화면 피드백 예시이며 실제 서비스 기능이 아니다.
