# 3D 방식 — 입체 건축 설명 영상

사용자 지정 명칭(2026-09-30): 앞으로 **3D 방식**이라고 부른다. 애니메이션 방식·시네마틱 방식과 구분하는 제작 지침이며, 운영 앱에 새 선택 항목을 배포했다는 뜻은 아니다.

| 이름 | 주된 표현 | 기본 제작 경로 |
| --- | --- | --- |
| 애니메이션 방식 | 그림·캐릭터·2D 도해로 설명 | 일러스트 + 코드 애니메이션 |
| 시네마틱 방식 | 촬영한 듯한 장면, 빛·질감·현장감 | 장면 이미지 + Higgsfield 영상 + 편집 |
| **3D 방식** | 입체 모형을 돌려 보고, 분해·조립·단면으로 원리를 이해 | Blender 3D 렌더 또는 AI 3D 스타일 영상 + 정확한 구조 렌더 + 편집 |

## 연출 기준

- 참고: [신비한 건축사전](https://www.youtube.com/@%EC%8B%A0%EB%B9%84%ED%95%9C_%EA%B1%B4%EC%B6%95%EC%82%AC%EC%A0%84_1/shorts)의 입체 건축 설명 표현. 제작 도구는 미확인. 타인 영상·음원·프레임을 다운로드하거나 재사용하지 않는다.
- 말하는 대상이 화면에 직접 등장한다. 전체 건물 → 특정 부분 접근 → 부품 분리 → 작동 원리 → 전체 복귀 순으로 구성한다.
- 미니어처 같은 실제 입체, 모서리 두께, 접촉 그림자, 콘크리트·유리·금속의 재질 차이를 표현한다. 평면 도표로 갑자기 전환하지 않는다.
- 한 장면에서 한 원리만 설명한다. 화살표·색 강조는 구조에 붙이고 큰 텍스트 카드가 그림을 대신하지 않는다.
- 동일한 모형·재질·배경·조명 방향을 유지한다. 중간에 파란색 단색 배경으로 바꾸지 않는다.
- 자막은 중앙, 2줄 이내의 짧은 구절. 굵은 고딕, 따뜻한 흰색 + 골드 핵심어, 얇은 외곽선·그림자. 주요 부품은 자막 뒤에 숨기지 않게 구도를 설계한다.
- Shorts 음성은 기존 Yooni(`n2fbxG88jqAoaVPUy3IG`), 1.15배속. 롱폼은 1.0배속. 대본 실측 길이에 장면을 맞추고 불필요한 정지·침묵을 늘리지 않는다.

## 재사용할 제작 순서

1. 주제·공식 근거를 확인하고 대본을 쓴다. 실제 사례와 일반 원리·가상 모형을 구분한다.
2. 각 대사에 `보여줄 물체 / 움직임 / 카메라 / 확인할 사실`을 대응시킨다. 대사보다 그림만으로 이해되는지를 우선한다.
3. **정확한 부품 수·연결·단면은 Blender**로 모델링한다. 모델링 좌표·조립 순서·카메라를 코드와 함께 보존한다.
4. 배경·현장감이 필요한 장면은 **Higgsfield의 3D 스타일 생성**을 선택할 수 있다. 기준 이미지 → 짧은 i2v → 일관성 검수. 생성 영상은 편집 가능한 3D 모델이 아니며 구조해석 결과도 아니다.
5. 현재 공식 모델 사양·견적을 조회하고 승인된 범위에서만 생성한다. 외부 API를 호출하는 코드는 ‘코드만으로 만든 3D’로 표기하지 않는다.
6. TTS 실측 → 장면 길이 조정 → 자막 → 배경음·효과음 → 9:16/1080×1920 합성. AI 영상에 자막을 생성시키지 않는다.
7. 시작·중간·끝 프레임, 실제 움직임, 음성 누락·긴 공백, 자막 겹침, 전체 디코드·길이·해상도를 확인한다. 영상 테스트와 실제 게시를 구분한다.

## 3D 스타일 생성 프롬프트 틀

> Original high-quality architectural miniature, physically coherent geometry, warm off-white concrete, brushed bronze steel, restrained tinted glazing, soft studio daylight, warm neutral seamless environment. Show [one mechanism] by [specific motion]. Camera [one deliberate movement]. Preserve the exact same building and components throughout. No lettering, captions, labels, logos, diagrams, flat slides, object morphing or blue background. Vertical 9:16, subject arranged around a reserved central subtitle band. Conceptual explanatory model, not real site footage.

실측 수치·법령·하중 경로는 프롬프트만으로 검증되지 않는다. 구조 설명은 원자료와 모델을 직접 검토한다.
