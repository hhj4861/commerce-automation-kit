# 「상품정보 → 상품상세 + 쇼츠 → 유료 광고 → 조회수 1,000」 E2E 테스트 설계 (2026-09-06)

이 문서는 팔려는 서비스 자체를 한 번 리허설하는 절차다. 고객이 **상품정보**를 주면
① 상품상세(페이지)를 만들고 ② 쇼츠 영상을 만들어 채널에 올리고 ③ 유료 광고로 그 쇼츠의
**조회수 1,000**을 만든 뒤 ④ 결과를 보고한다. 지표는 노출(impressions)이 아니라 **조회수(views)**다.

> 이전 판(노출 1,000 기준 수동 실측)은 이 문서로 대체했다. Meta PoC(`packages/meta-paid-reach`)는
> 아직 노출 기준이며, 조회 지표 확장은 §7 후속 작업이다.

## 0. 공식 문서로 확인한 사실 (2026-09-06, Google Ads 고객센터)

| 사실 | 의미 |
|---|---|
| Shorts 광고는 **동영상 조회(Video view) 캠페인**의 "멀티 포맷 광고" 섹션에서 YouTube Shorts를 체크해 산다. 문서가 "Shorts ads only VVC"를 언급하므로 Shorts 단독도 가능하다(입찰 추천값은 부정확할 수 있음). | 조회 기준 과금(CPV)으로 Shorts만 살 수 있다 |
| Shorts 광고의 과금 조회(TrueView view)는 **10초 이상 시청 또는 끝까지 시청**(10초 미만 영상), 혹은 CTA·좋아요·댓글·공유 상호작용이다. | "조회수 1,000" = 10초 이상 본 사람 1,000명 |
| 광고로 발생한 조회는 **YouTube 공개 조회수에 포함**된다(Shorts 광고 형식 포함). | 고객이 영상에서 직접 "1,000회"를 볼 수 있다. 정산 근거는 Google Ads 보고서, 확인 근거는 Studio 조회수 |
| 캠페인 총예산은 YouTube 캠페인에서 지원되며 시작·종료일 필수, 최소 3일, 총예산 초과 청구 없음. | 예산 상한이 Google 쪽에서 강제된다 |
| 소재는 9:16 권장, Shorts 피드에서는 처음 60초만 재생, 유튜브에 공개/미등록으로 올라가 있어야 한다. | 미등록으로 올려도 광고는 되지만, 공개 조회수를 고객에게 보여 주려면 **공개** 업로드 |

## 2. 실행 절차 (1회차)

### 2-1. 접수

고객(또는 파일럿용으로 본인)이 아래를 준다. 이 항목이 곧 브리프 템플릿 초안이다.

- 상품명, 카테고리(화장품/건기식/식품/생활…), 핵심 특징 3개, 성분/스펙, 가격, 판매 페이지 URL(있으면)
- 사용권 있는 상품 실사진 3장 이상 (타사 이미지·상세페이지 캡처 금지 — CLAUDE.md 금지선 #1)
- 브랜드명·로고 사용 허락, 광고 집행 동의(누구 채널에서 어떤 문구로 나가는지)
- 타깃 시장(한국/일본), 광고 기간 희망

### 2-2. 상품상세

- 일본 시장이면 `/product-page <상품>` 스킬 → product-page-gen 렌더(약기법 lint block 0이어야 함).
- 한국 시장이면 product-page-gen을 `locale: 'ko'`로 렌더해 본다(한국 화장품법 lint 11규칙은 있음). 결과가 부족하면
  1회차는 **사람이 작성한 간단 상세(HTML 1장)** 로 대체하고, ko 템플릿·한국 표시광고법 lint 보강을 §7에 올린다.
- 상세를 Pages에 배포해 랜딩 URL을 확보한다. 광고 랜딩은 반드시 실제로 열리고 영상 내용과 일치해야 한다.

### 2-3. 쇼츠 제작 (기존 쇼핑쇼츠 공정, 파트너스 링크 없이)

1. 대본: shopping-shorts lint 통과(질병 효능·가짜 경험담·절대 보장 block) → apps/shopshorts에서 사람 승인.
2. 클립: ad-video 스킬로 9:16 클립 생성(상품 실사진 기반 i2v 우선).
3. VO: tts-narration `script --join`.
4. 조립: 자막·BGM 더킹·**"(광고)" 오버레이**. 길이 15~45초(10초 이상 시청이 조회 기준이므로 첫 10초가 승부).
   **훅 변형 3종을 한 세트로 만든다**(2026-09-06 결정): 바디·CTA 클립은 공유하고 훅 3초 클립만 3개 —
   A 문제 제시형(갈라진 손등), B 결과 선공개형(종이 테스트 먼저), C 호기심형("뭘 발랐을까요").
   잡 파일 `docs/templates/handcream-pilot/shorts.job.hook{A,B,C}.json`(lint 통과). 종이 테스트 비트가 7초에 시작하도록 발림 비트는 4초.
5. 업로드: `youtube-upload` `--privacy public`, 제목·설명에 "(광고)"와 랜딩 URL. 영상 ID 기록.

### 2-4. 광고 집행 (Google Ads, 수동)

계정·결제·채널 연결은 Meta 가이드와 같은 수준의 준비가 필요하다(`ads.google.com`, 한국·서울·KRW,
선결제 가능하면 선결제). 캠페인은 다음으로 만든다.

| 설정 | 값 |
|---|---|
| 목표 | YouTube 도달범위·조회·참여 |
| 유형 / 하위유형 | 동영상 / **동영상 조회**(Video views) |
| 입찰 | 타겟 CPV(또는 조회수 최대화). 첫 회는 Google 제안값 |
| 예산 | **캠페인 총예산**, 시작·종료일(최소 3일) |
| 네트워크 | YouTube만, 동영상 파트너 OFF |
| 위치 / 언어 | 대한민국 / 한국어 (일본 시장이면 일본/일본어) |
| 멀티 포맷 광고 | **YouTube Shorts만 체크** (인스트림·인피드 OFF) |
| 광고그룹 타깃 | 첫 회는 기본값(전체). 두 번째부터 상품군 관심사 |
| 광고 | **광고그룹 1개에 광고 3개**(훅 A/B/C 영상 각각). Google이 조회율 좋은 광고에 노출을 몰아 준다. 최종 URL = 2-2 랜딩, 헤드라인·설명은 승인된 문구 |

### 2-5. 관찰과 정산

- 하루 2번: Google Ads의 **조회수·노출수·조회율·평균 CPV·비용**, Studio의 **공개 조회수**를 나란히 기록한다.
  두 조회수의 차이가 "광고 조회가 공개 카운터에 얼마나 반영되는가"의 실측이다.
- Google Ads 조회수 1,000 도달 시각을 적는다. 정산 기준은 Google Ads 조회수, 고객 확인 기준은 Studio 조회수로 둔다.
- 총예산을 다 쓰고도 1,000에 못 미치면 **미달 보고**한다(숨기지 않는다). 이 경우 CPV가 곧 원가 문제다.

## 3. 예산 산정

총예산 = 목표 조회 1,000 × 예상 CPV × 여유 1.5(초과·심사 지연 흡수).
제작비(힉스필드, pro 1.75cr/s): 공유 클립 3개(4+4+4초) 21cr + 훅 3개(3초) 15.75cr + TTS ≈ **38cr/세트**. 시안(std) 실측 24cr. 예상 CPV는 **실측 전엔 모른다**.
1회차는 거꾸로 간다: 총예산 상한(예 30,000원)을 정해 두고 "이 돈으로 조회가 몇 개 오는가"를 재서 CPV를
얻는다. 2회차부터 CPV로 1,000 도달 예산을 역산한다.
