## 제작 전 계획과 검토

- 색: 브랜드 `#5261ce`, 본문 `#272b38`, 보조 `#686d7c`, 바탕 `#fafaf9`, 표면 `#ffffff`, 경계 `#e9eaf0`. 연한 브랜드 면은 `#f0f1fc`, 정답에만 초록을 쓴다.
- 글꼴: 한국어 Apple SD Gothic Neo/Noto Sans KR 시스템 글꼴. 일본어 Hiragino Sans/Yu Gothic. 제목 24–27px/600, 학습 문장 23–27px/500, 본문 15px/400, 보조 13px/400. 모든 글을 굵게 만들지 않는다.
- 배치: 모바일의 상단은 짧은 현재 과업, 본문은 왼쪽 정렬된 말과 학습, 하단은 입력과 탐색. 음악의 현재 가사만 가운데 정렬해 노래를 읽는 호흡을 만든다. PC는 탐색·본문·참고 영역을 유지한다.
- 고유성: 한마디의 학습 문장을 중심에 두고 음성을 듣고 대화에 쓰는 조작만 가까이 배치한다. 소개용 그림·임의 수치·장식용 태그를 추가하지 않는다.

사전 비평: 둥근 카드에 옅은 색만 입히는 수정은 이전과 같은 인상을 남긴다. 따라서 스터디의 채워진 3단 선택을 밑줄 탭으로 바꾸고, 대화에서는 큰 제목/상황 행/날짜의 중복을 줄인다. 선택된 하단 메뉴의 큰 사각 배경을 없애고 아이콘에만 작은 선택 표시를 둔다. 모서리는 입력 28px/학습 면 22px/버튼 12px로 역할에 맞게 구분한다. 그림자와 파란 면은 주요 대상에만 쓴다.

## 검증

2026-10-15 시안 검토 완료. 디자인 확정·실서비스 반영·Flutter 구현·운영 배포를 뜻하지 않는다.

- Chrome 390×844, 320×568, 1440×900에서 검토했다. 320px 대화 입력 끝 y479, 하단 탐색 시작 y494로 겹치지 않는다. 번역 입력 끝 y442로 본문 끝 y494 안에 보였다(간격 보완 전 측정이며 이후 입력 간격은 줄였다). 가로 넘침은 관측하지 않았다.
- 메뉴를 다녀와도 미전송 초안이 유지됨을 확인했다. 음악 정답 피드백 → 다음 줄의 가사·단어 동시 변경 → 선택한 문장의 AI 대화 입력 연결을 실제로 눌러 확인했다. PC 대화 입력 끝 y844, 900px 화면 안에 노출되며 참고 패널을 유지한다.
- 390px 제품 화면에서 음악의 단어 저장·대화 연결 버튼과 번역 결과 저장을 확인했다. 캡처 비평에서 번역 저장 버튼이 첫 화면 아래로 밀린 것을 발견해 제목·입력·결과 간격을 줄였다. 최종 번역 저장 버튼 끝 y732, 탐색 시작 y770으로 첫 화면에 들어온다.
- 주요 보조 글자·브랜드·탐색 색 조합 5개의 명암비를 계산해 4.53–5.30을 확인했다. 전체 접근성 인증이나 VoiceOver 검증을 의미하지 않는다. 작은 복습 화살표의 터치 영역은 44×44px로 보완했다.
- JS 구문·Git 공백·draw.io 고유 ID·XML 파싱·XML 포함 SVG·PNG 8개 파일의 디코딩을 검증했다. HTML 렌더에서 페이지 JS 오류는 없었다. 모바일 보드·같은 크기의 전후 비교·번역·PC 캡처를 시각 검토했다.
- 최초 미리보기 서버는 샌드박스의 소켓 바인딩 거부로 시작되지 않았다. 해당 실패 종료를 확인한 뒤, 두 디자인 폴더만 허용하는 127.0.0.1 전용 서버를 허용된 실행 경로로 시작해 검증했다. 검증용 서버는 작업 후 정상 종료한다. 상시 게시 URL은 없다.
- 실제 휴대폰 키보드, 음성 권한, 네이티브 재생, Flutter 렌더는 이번 HTML 시안에서 검증하지 않았다.
