# 메시지를 먼저 구성하는 시나리오

## 변경 이유

심리학 프로젝트 `c4a6acd5-7649-4c99-b6ec-11bbb5e85046`의 24초 대본은 화면 연출에 비해 전달할 설명이 부족했다. 기획 추천은 초 단위 동작을 중심으로 작성됐고, 시나리오 프롬프트에는 내레이션을 짧게 쓰라는 지시와 `짧은 내레이션` 예시가 있었다.

## 적용 범위

- `lib/studio-editorial.js`에서 7개 카테고리의 구성 기준을 공유한다. 심리학은 공감할 상황 → 이해할 이유·관점 → 구체적인 말·행동을 담는다. 건축학·역사·과학에는 원리·배경·예시가, 광고에는 제공된 제품 사실이, 드라마에는 인물의 갈등·대사·반전이 중심이 된다.
- 기획 추천의 주제와 분위기 모두 메시지와 설명할 내용을 먼저 제안하고 화면 연출을 덧붙인다. 최근 검색 확인과 출처 반환 조건은 유지한다.
- 시나리오는 메시지 → 이어지는 내레이션 → 문장과 호흡에 맞춘 장면 → 보조 화면 순서로 작성하도록 지시한다. 상황극만으로 설명이 빠지지 않도록 자체 검토 지침을 추가한다.
- 선택한 길이를 늘리지 않는다. 설명 중심 대본은 초당 공백·문장부호 제외 3~4.5자를 초안 참고치로 제시한다. 실제 TTS 측정값이나 엄격한 합격 기준은 아니며 대화·침묵·사용자의 여백 요청은 허용한다. 실제 음성 재생 길이와 내용 검수는 별도로 필요하다.
- Codex·Claude의 기존 생성 경로에 공통 적용한다. API·저장 스키마, 호출 횟수, 모델 선택, 취소 신호, 출력 길이 검증을 변경하지 않는다. 자동 재시도나 추가 생성 비용을 도입하지 않는다.

## 검증

- Shopshorts 및 credential-broker 회귀 테스트 185개 통과. 카테고리 분기, 숏폼·롱폼 지침, 두 공급자에 대한 프롬프트 전달, 모델·취소 신호 유지, 입력·응답 계약 보존을 포함한다. 테스트 대역으로 의미적 품질이 입증됐다고 간주하지 않는다.
- Cloudflare Pages Functions 빌드 통과. UI 변경이 없어 새 브라우저 화면 검증은 수행하지 않았다.
- 로컬의 기존 Codex 구독 실행기로 같은 24초 기획을 실생성했다. 최종 지침에서 4장면·24초, 내레이션 70자(공백·문장부호 제외)가 반환됐다. 기존 54자와 비교해 상황 설명과 책임·실천 문장이 추가됐다. 글자 수 증가는 품질 점수가 아니다.
- 최종 24초 예시: “엄마, 이것 봐! 잠깐만!” → “일도 집안일도 밀려 마음이 급했어요. 그래도 말은 내 책임이죠.” → “아까 목소리가 컸지. 미안해. 무슨 이야기였어?” → “내가 뭐에 쫓겼는지 돌아보고, 아이 말을 들어요.”
- 같은 주제에 60초·설명 중심 방향을 넣은 별도 실생성은 6장면·60초·195자였다. 구체적 사건 → 그날의 부담 → 돌아볼 관점 → 아이에게 부담을 맡기지 않기 → 사과의 예 → 자신을 돌볼 행동으로 이어졌다. 24초 결과는 약 35초, 60초 결과는 약 37초에 생성됐다. 이는 한 번의 관측이며 응답 시간 보장이 아니다.
- Claude 실제 구독 호출, TTS 청음, 영상 생성은 이번 검증에 포함하지 않는다. 프롬프트는 품질을 유도하며 모든 생성의 의미적 품질이나 근거 확인 성공을 보장하지 않는다.

### 60초 실생성 내레이션 (검증용 가상 상황, 운영 미저장)

> 저녁 준비 중 아이가 물을 쏟자, “너까지 왜 그래!”라는 말이 나왔어요.
>
> 그날은 퇴근 뒤에도 업무 연락이 이어졌고, 부모는 점심도 거른 채 저녁을 준비하고 있었죠.
>
> 쏟아진 물에 대한 말에, 하루의 부담까지 섞인 건 아닌지 돌아볼 수 있어요.
>
> 하지만 아이가 그 부담을 달래야 하는 건 아니에요. 잠깐 숨을 고르고 이렇게 말해보세요.
>
> “아까 날카롭게 말한 건 미안해. 내가 지쳤어도 너한테 그렇게 말하면 안 됐어. 물은 같이 닦자.”
>
> 그리고 내 식사도 챙겨요. 오늘은 설거지를 잠시 미루고, 저녁부터 먹어도 괜찮아요.

## 운영 반영

PR별 머지 승인을 받은 뒤 운영 체크아웃을 승인된 커밋으로 갱신하고, 계정 실행기의 활성 작업 종료를 확인한 후 재시작한다. Pages Functions도 같은 커밋으로 배포한다. Broker 배포·시크릿 변경은 필요하지 않다.

새 추천과 새 시나리오 생성부터 적용된다. 기존 프로젝트의 기획·대본은 자동으로 덮어쓰지 않는다. 24초 안에서는 한 가지 메시지에 집중하며, 더 충분한 설명을 원하면 사용자가 영상 길이를 늘린 뒤 재생성한다. 이번 실생성 결과는 검증용이며 운영 프로젝트에 저장하지 않았다.
