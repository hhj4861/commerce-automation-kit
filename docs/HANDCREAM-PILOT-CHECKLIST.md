# 핸드크림 파일럿 — 소싱·스마트스토어 등록 체크리스트 (2026-09-06)

사람이 해야 하는 일만 모았다. 끝나면 `docs/templates/handcream-pilot/` 브리프를 채우고
`docs/YOUTUBE-SHORTS-1000-VIEWS-E2E-TEST.md` §2 로 넘어간다.

> **공식 확인** = 2026-09-06 찾기쉬운 생활법령정보(easylaw.go.kr)·식약처 안내 원문 확인.
> 표시 없는 항목은 일반적 절차이며 네이버 판매자센터 화면에서 재확인한다(네이버 도메인은 자동 접근 불가).

## 1. 법적 전제 (공식 확인)

- **화장품책임판매업 등록은 필요 없다** — 이미 등록된 책임판매업자로부터 완제품을 구매해 소비자에게 단순 판매(소매)하는
  경우는 화장품법 영업등록 대상이 아니다. 단, **직접 제조·위탁제조(OEM/자체 브랜드)·수입·구매대행**은 등록 대상이므로
  이번 파일럿에서는 하지 않는다.
- **통신판매업 신고**는 필요하다 — 사업자등록 → 네이버에서 구매안전서비스 이용확인증 발급 → 정부24 통신판매업 신고.
- 개인 판매자로도 스마트스토어 개설은 가능하지만, 광고 집행·정산·세금계산서를 생각하면 **사업자 판매자**로 간다.

## 2. 소싱

- 국내 **책임판매업자가 등록된 완제품**만. 제품 뒷면 표시사항에 "화장품책임판매업자: ○○" 가 있어야 한다.
- 도매 채널(도매꾹·도매매·오너클랜 등 B2B 몰) 또는 브랜드사 직거래. 최소 주문 수량과 **온라인 판매 허용 여부**(브랜드 가격
  정책·병행 금지 조항)를 서면으로 확인한다.
- 수량: 파일럿은 판매가 목적이 아니라 파이프라인 검증이다. 촬영용 + 초기 주문 대응분(예 20~30개)이면 충분하다.
- 받으면 기록: 정식 상품명, 브랜드, 용량, 전성분 전체(라벨 순서), 사용기한/제조번호, 책임판매업자, 포장 포함 중량(g),
  매입 단가, 공급사 제공 자료(있으면 사용 허락 범위).

## 3. 사진·영상 권리

- **본인 촬영**이 원칙. 흰 배경 제품컷(hero), 제형 클로즈업(texture), 손등 발림 장면(usage) 최소 3컷.
- 공급사 제공 이미지는 **서면 사용 허락**이 있을 때만 `origin: supplier-licensed` 로 쓴다.
- 브랜드 공식몰·타 판매자 상세페이지·리뷰 사진은 쓰지 않는다(금지선 #1).
- 쇼츠 클립은 본인 촬영 사진을 시드로 힉스필드 i2v 생성(`aiLabeled` 표기).

## 4. 스마트스토어 등록

1. 판매자센터 가입(사업자) → 스토어명·대표 이미지 → 정산 계좌.
2. 상품 등록: 카테고리 화장품/미용 > 바디케어 > 핸드크림(화면 명칭 확인). 화장품 **필수 표시정보**(용량, 제조사·책임판매업자,
   사용기한, 사용법, 주의사항, 품질보증기준) 입력 — 라벨 그대로.
3. 상세 설명: product-page-gen 이 만든 HTML 은 스마트에디터에 그대로 붙지 않을 수 있다(HTML 직접 입력 지원 여부 **미확인**).
   안 되면 HTML 을 긴 이미지로 변환해 올린다:
   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
     --window-size=750,6000 --screenshot=detail.png "file://$PWD/out/handcream-pilot-001/index.html"
   ```
   (세로 길이는 렌더 결과에 맞춰 조정. 실제 붙이기 전에 화면에서 확인.)
4. 상품 URL 확보 → 광고 최종 URL 이자 쇼츠 설명란 링크. 공개 상태에서 실제로 열리는지 확인.

## 5. 브리프 채우기

`docs/templates/handcream-pilot/` 의 두 JSON 을 2·3에서 기록한 값으로 채운다. 그다음:

```bash
npm run cli -w @cak/product-page-gen -- validate --brief docs/templates/handcream-pilot/product-page.brief.json
```

통과하면 `/product-page` 스킬 흐름(카피 생성 → lint → 사람 승인 → 렌더)으로 상세를 만들고, 쇼츠는
`.claude/skills/shopping-shorts` 흐름(대본 → lint → 승인 → 클립 → VO → 조립)으로 만든다. 조립 결과에
"(광고)" 오버레이가 들어가 있는지 눈으로 확인한다.

## 6. 확인하지 못한 것 (PROGRESS §7)

- 스마트스토어 화장품 카테고리 판매 시 추가 서류 요구 여부(단순 유통 기준).
- 스마트에디터 ONE 의 HTML 직접 입력 지원 여부 → 이미지 변환 경로 필요성.
