## A. 연결(이 파이프라인의 핵심)
- A1 컷 N 의 끝 장면 = 컷 N+1 의 시작 장면 ("c2 의 종료장면과 c3 의 시작장면이 이어져야").
- A2 앞 회차 마지막 컷 = 다음 회차 첫 컷 ("1화의 마지막이 2화의 1회차가 되는건 유지").
- A3 컷마다 배경이 이어진다(세트가 바뀌지 않음) ("배경이 이어지지가 않고").
- A4 문맥이 이어진다 — 대사가 앞 장면에 반응, 흐름이 자연스럽고 회차가 너무 요약되지 않음, 뜬금없는 대사 금지("박반장 멘트가 너무 뜬금없는").
- A5 인물 얼굴·의상이 컷마다 유지(서윤: 검은 딥 V넥 + 열린 회색 조끼, 일부 프레임 조끼 누락 사례).
- A6 소품 상태가 이어진다(쪽문 열림/닫힘, 잠금쇠, 도끼 위치 등).
- A7 세계관 규칙이 회차 내내 지켜진다 — 좀비는 머리를 베야 죽고 몸통 타격으로 쓰러지지 않음.
- A8 인물 목소리가 컷·회차마다 같아야 한다(생성 음성이 컷마다 달라지는 문제는 아직 명시적 요구는 아니나 A5 와 같은 성격 — 점검 대상).

## B. 생산 공정·품질 관문
- B1 크레딧 낭비 없이 "동적으로 지침을 넣어" 첫 생성 품질을 높인다(컷별 시행착오 테스트 지양).
- B2 이미지(키프레임) 먼저 확정 후 영상(참고 영상 5편 공통 공정).
- B3 컷마다 시나리오대로 나왔는지 판정해 pass 여야 다음으로(방식 A: 자동 판정 pass 면 진행, 사람은 파일럿 2컷·예외 통과·회차 미리보기).
- B4 시나리오 확정 전 교차 리뷰: Claude 작성 → Codex 리뷰, Codex 작성 → Claude 리뷰.
- B5 리뷰 통신은 세션 무관 토큰 기반, 에이전트별 키는 GCP Secret Manager(`gen-lang-client-0881453127`).
- B6 Codex 에서도 같은 구조로 실행 가능(이식은 Codex 담당).
- B7 장르 약속(첫 10초 훅·사이다·복수 등) 회차마다 충족, 기준을 낮추지 않음.
- B8 수위: 15세 장르 액션 허용(물린 자국, 무기 위협, 컷어웨이 처치), 피 튀김·노출 상처 금지. 관능은 암시만, 성인, 노출 금지 — 대본뿐 아니라 생성 결과물에도 적용되어야 함.
- B9 대사량: "각 컷들의 대사가 너무 부족" — 대사가 충분해야 한다(컷당 대사 상한 규칙과 충돌 여부 점검).
- B10 대사가 실제 영상에서 정확히 들려야 함(받아쓰기 대조). 비명 같은 비어휘 발화 처리.
- B11 참조 영상을 쓸 때 음성이 따라 들어가지 않게.

## C. 비용·승인
- C1 유료 생성 전 비용 제시·승인, 승인 범위 안에서만 생성. 결제·플랜 변경은 사용자.
- C2 480p 초안 → 마음에 든 것만 1080p 확정(초안 7일 내 확정 가능).
- C3 재생성 상한·실패 컷 비용 통제.

## D. 산출물·배포
- D1 쇼츠(9:16) 먼저, 나중에 롱폼(16:9, 회차당 8~10분)으로 전환 가능.
- D2 쇼츠 조립: 제목·머리글 고정, 자막 스타일·OFL 폰트, 콜드 오픈, 컷별 다듬기, 상단 AI 문구 제거(플랫폼 AI 표시는 필수).
- D3 YouTube·릴스·틱톡 업로드는 매번 명시 허락, 업로드 메타(제목·설명·해시태그).
- D4 배경음악은 생성 단계에서 빼고 후반에 넣는다(설계 결정).

## E. 운영·규칙
- E1 파이프라인은 같은 세션에서 이어지지 않는다 — 상태는 파일·토큰에, 새 세션이 이어받을 수 있어야 함.
- E2 한 회차는 한 에이전트가 진행(잠금·인계).
- E3 저장 위치: 드라마 미디어 `~/Downloads/vedio/drama/<날짜-작업>/`, 임시 산출물 iCloud `claude 작업/`, 비밀값은 로컬·SM 만.
- E4 금지선: 타인 콘텐츠 재사용·스크래핑 금지(참고는 트로프 수준), 공식 API 만, 실패 침묵 금지, 사람 게이트 유지.
- E5 이미 만든 1화(legacy)는 앞 회차로 읽히고 롱폼 전환 때 재조립 가능해야 함.
