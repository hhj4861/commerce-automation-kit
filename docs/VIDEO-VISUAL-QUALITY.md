# 공통 영상 연출 개선

상태: 작업 브랜치 구현, 운영 미배포. 기존 완성 영상과 저장 프로젝트를 소급 변경하지 않는다.

## 참고와 실제 적용

브라우저에서 [해운대 영상](https://youtu.be/lQaYhIJePu0)의 해안 전체 → 수중 모래 → 잠제 → 입자 흐름 → 전체 구도 연결을 확인했다. [석빙고 쇼츠](https://youtube.com/shorts/G92FEJcia4o)는 얼음·돌의 재질 차이와 세부 장면을 참고했다. 영상 자산·대본은 다운로드·재사용하지 않았고 사용 도구나 기술적 주장을 검증했다는 뜻은 아니다.

새 프로젝트의 explain-v1 계획을 CLI/웹 동일 scenarioResult → directScenario로 검증한다. 각 장면에 대상, 시작, 동작, 결과, 연속성, 재질, 조명, 구도를 저장한다. 반복 설명·전체 구도 3연속·12초 초과 단일 구도·잘못 배치된 요약은 생성 전에 실패로 표시한다. 실제 미디어 프롬프트에 시작20%/동작60%/결과20%, 대상 분리와 공통 화풍을 전달한다.

마지막 4~6초의 요약만 검증된 문구 세 개로 기존 HyperFrames summary에 연결한다. 임의 HTML·템플릿 경로는 허용하지 않는다. 가로 summary도 실제 렌더한다. 애니메이션은 기존 animationPlan 엔진을 유지한다. 승인·비용·제공자 경로는 유지한다.

수동/자동 새 쇼츠 기본45초, 첫 질문은 0~3초 편집 가능한 상단 자막. 사용자가 삭제한 저장 편집에는 재삽입하지 않는다. 롱폼 첫15초와 쉬운 제목 기준은 공통 추천/대본 지침에 적용한다. 설명 기본 태그는 카테고리 관련 항목만 제안한다. 본편URL은 검증·저장하되 manual-required 인계로 표시하며 실제 YouTube 연결 완료를 가장하지 않는다.

## CLI

`node apps/shopshorts/studio-visual-plan.mjs --project project.json --out plan.json`

입력: brief/title/visualStyle/scenes. 출력: 검증 장면, 품질 검사, 공급자별 프롬프트, 설명 제안. 유료 호출 없는 공통 계획 컴파일러다. 임의 Blender 코드 생성기나 모든 독립 스크립트의 자동 이관 기능은 아니다.

## 검증·한계

집중 검사7개 통과: 웹/CLI 동일 계획, 불량 계획 거부, 자산 무효화, 실제 HyperFrames 1920×1080/180프레임 렌더·전체 디코드, 질문 자막 및 삭제 유지, 관련 URL 인계. 최종 전체 회귀 결과는 아래 기록한다.

구조 검사는 미적 품질·사실성·조회수를 보장하지 않는다. 실제 유료 생성 결과는 시청 검수가 필요하다. 애니메이션 지원 도형 범위, 별도 3D 레시피의 개별 연출, 수동 대본 수정 후 요약/방향 재검수는 남는다. 모든 주제의 임의3D모델을 만드는 새 엔진이 아니다. 코드 변경은 기존 업로드의 썸네일 변경·채널 설정·본편 연결 완료가 아니다.

최종 전체 회귀: Node 20, `node --test apps/shopshorts/test/*.test.mjs` **333/333 통과, 실패/skip 0**. HyperFrames는 별도 Node 22 실행기를 사용했다.

Chrome 실제 브라우저 → 로컬 API → 워커 HyperFrames → 편집 → 최종 MP4 E2E도 통과했다. 첫 질문 자막, 45초 기본값, 모바일 가로 넘침, 최종 미디어와 편집 모니터를 확인했다. 픽셀 검사에서 발견한 질문 줄바꿈 깨짐은 한 줄 크기 조절로 수정하고 실제 프레임을 다시 확인했다. E2E 대본·도입은 테스트 자료이며 유료 생성·업로드는 하지 않았다.
