# 한마디 2.0 디자인 목업

2026-09-29 · 디자인 검토용 v1 · **UI/UX 승인 전 / 실제 앱 미구현**

사용자 승인 경계: 디자인 시안 → 클릭 가능한 목업 → UI/UX 승인 → 앱 구현. 이 폴더는 독립적인 디자인 산출물이며 운영 앱·API·계정·학습 기록을 변경하지 않는다. 문서용 목업이므로 현재 프로젝트 `docs/`에 저장한다.

## 디자인 방향

말할 때 펼쳐 보는 작은 여행 노트. 일본어를 읽지 못하는 사람도 한국어 뜻과 큰 음성 버튼만으로 시작한다. 스터디에서는 여유 있게 한 문장을, 번역에서는 지금 필요한 뜻을 크게 보여준다.

- 색: 종이 `#FBFCFE`, 여행 파랑 `#3157D5`, 잉크 `#182B49`, 살구 `#FFD6B8`, 연한 민트 `#DDF3E8`, 보조 글자 `#5A6980`.
- 글자: Apple SD Gothic Neo / Noto Sans KR / Malgun Gothic의 시스템 한글 폰트. 제목 28~32px, 본문 15~17px, 보조 13px. 별도 웹폰트 요청 없음.
- 형태: 말풍선을 브랜드 모티브로 사용. 모든 정보를 같은 카드에 담지 않고 큰 말하기 과제, 줄 단위 학습 목록, 언어별 번역 면을 구분한다. 외부 사진·생성 이미지 없음.
- 정렬: 설명·문장은 왼쪽, 마이크·짧은 행동은 중앙. 한 손 조작 영역에 주 행동을 둔다.
- 학습 동선: 스터디 / AI 대화 / 번역 / 내 표현. 언어·시간은 설정으로 모은다.

초안 검토: 일반 대시보드처럼 숫자·진행률 카드를 여러 개 쌓는 안을 제외했다. 여행에서 실제로 말할 한 문장과 두 언어의 번역 면을 시각적 중심으로 삼았다. 학습 성취를 꾸며 보여주는 점수·연속 출석 압박을 넣지 않는다.

```text
스터디                    번역
언어 · 설정               한국어 ⇄ 일본어
오늘 말할 한 문장          상대 말 / 한국어 뜻
큰 연습 시작 버튼          내 말 / 일본어 + 발음 도움
내 대화에서 온 수업        두 개의 큰 말하기 버튼
기본 과정                 종료 → 학습에 추가
──────────── 네 개의 하단 탭 ────────────
```

## 열기와 검토

`index.html`을 브라우저에서 연다. 같은 폴더의 CSS·JS가 필요하다. 인터넷·빌드·로그인 없이 동작한다. 데스크톱은 휴대폰 화면과 검토 메뉴, 모바일은 앱 화면만 보여준다.

1. 번역 → 상대 말 듣기 → 내 말 전달 → 대화 마치기 → 표현 선택 → 내 학습에 추가.
2. AI 대화 → 카페에서 주문 → 말하기 체험 → 말하기 끝내기 → 대화 마치기 → 표현 선택 → 내 학습에 추가.
3. 스터디 → 내 대화로 연습하기 → 듣기·따라 말하기·역할 연습 → 내 표현에서 결과 확인.
4. 첫 시작·설정에서 일본어/태국어 전환, 내 표현 삭제도 확인한다. 상단 **디자인 목업 · 화면 체험** 메뉴에서 연결 실패 화면과 초기화를 선택한다.

음성·번역·AI 응답은 고정 예시다. 실제 마이크·음성 합성·네트워크·API를 사용하지 않는다. 모든 선택과 저장은 현재 페이지 메모리에만 있고 새로고침하면 초기화된다. 일본어·태국어와 발음 도움은 화면 설계용 예시로 출시 전 원어민 검수가 필요하다.

## 승인할 항목

- 파랑과 살구색 중심의 시각 방향, 글자 크기·화면 밀도
- 네 개 탭과 초보자 진입 흐름
- 여행 번역·AI 회화 → 표현 선택 → 맞춤 스터디 연결
- 음성 버튼·한글 발음 도움·실패/빈 상태·설정 위치

목업의 버튼은 디자인 체험만 진행하며 승인·배포를 실행하지 않는다. 실제 구현은 사용자가 UI/UX를 승인한 다음 별도 구현 worktree에서 진행한다.

## 검증

2026-09-29, macOS의 headless Google Chrome 154.0.8037.58에서 검증했다.

- 번역 → 선택 저장 → 스터디, AI 대화 → 선택 저장 → 동일 스터디·내 표현 반영 통과
- 듣기 → 따라 말하기 → 역할 연습 → 완료, 삭제, 언어별 표현 분리, 연결 실패·복구·고정 표현 통과
- 표현을 기본 선택하지 않음, 저장 전후 상태 변화, 모달 Escape 닫기, 사용자 주제 HTML 이스케이프 확인
- 360 / 390 / 768 / 1440px × 10개 화면: 가로 넘침 없음, 네 개 탭과 버튼 접근 이름 확인
- 브라우저 실행 오류 0, 외부 HTTP 요청 0. 새로고침 시 체험 데이터 초기화 확인
- [데스크톱 시안](preview-desktop.png)과 [여행 번역 시안](preview-translation.png)을 캡처해 시각적으로 확인

초기 검증에서 브라우저 전역 이름 충돌을 찾아 격리했고, 검토용 연결 실패 버튼을 제품 화면 밖으로 이동했다. 실제 모바일 기기·음성 인식·음성 품질·번역 정확도·백엔드·운영 E2E를 검증한 것은 아니다. 일본어/태국어 카페 표현을 중심으로 한 고정 샘플이며 자유 주제의 실제 응답 생성·자동 난이도 평가는 구현하지 않았다.

재현 스크립트는 `verify.mjs`다. 로컬 Google Chrome과 Playwright가 필요하다.

```sh
HANMADI_PLAYWRIGHT_PATH=/path/to/node_modules/playwright node docs/hanmadi-2.0-mockup/verify.mjs
```

스크린샷 두 파일을 다시 생성하므로 저장소 작업 시 해당 경로의 소유권을 먼저 등록한다. 브라우저 채널은 `HANMADI_BROWSER_CHANNEL`로 바꿀 수 있다. 검증 프로세스는 성공·실패 모두 브라우저를 종료한다.
