# Hanmadi 2.0 승인 시안 반영 수정

2026-09-29. 기존 운영 배포의 넓은 대시보드형 레이아웃이 사용자가 승인한 `docs/hanmadi-2.0-mockup/index.html#study`와 달라 수정했다. 이 문서는 구현 브랜치의 검증 기록이며 운영 적용 완료 기록이 아니다.

## 디자인 기준과 수정

- 목업의 시스템 한글 글꼴, 여행 파랑 `#3157D5`, 종이 `#FBFCFE`, 잉크 `#182B49`, 민트·살구색을 사용한다.
- 데스크톱 410px 앱 영역, 모바일 화면 폭, 앱 내부 스크롤과 항상 보이는 네 개 하단 탭으로 복원했다. 목업의 SVG 아이콘을 원본 경로 그대로 사용한다.
- 상단 언어 선택·내 AI·설정, 밑줄형 오늘 추천/레벨별/상황별 탭을 복원했다.
- 스터디: ‘나에게 맞는 다음 한마디’, 파란 추천 수업, 스몰토크·클럽 타일, 개인 대화 학습 연결.
- 레벨: 네 단계 선택, 실제 연습 수·진행 막대, 연결선이 있는 수업 목록. 선택/hover 대비 유지.
- 상황: 카테고리 필터, 아이콘·색상 타일, 상황 상세 및 단계별 수업과 AI 대화 진입.
- 번역: 두 언어 영역을 세로 배치하고 입력 언어 선택 아래 하나의 음성 버튼을 둔다. 390×844px 캡처에서 버튼이 하단 탭 위에 보인다.
- AI 대화·내 표현: 시안의 말풍선, 한글 발음 도움, 줄 단위 표현 목록과 동일한 글꼴·아이콘 체계 적용.
- 화면 전환 시 내부 스크롤을 제목 위치로 초기화한다. 모달의 키보드/닫기 동작과 기존 API 연결은 유지한다.

## 시연용 요소와 실제 데이터의 차이

목업 주변 ‘디자인 시안 01/직접 둘러보기/체험 초기화’ 검토 패널과 가짜 9:41 상태줄은 제품 UI가 아니므로 제공하지 않는다. 운영 학습 과정은 실제 8개 상황을 표시해 진행 분모가 8이며, 목업의 고정 4개 시연 수치를 복사하지 않는다. 로그인/레벨 체크, AI 연결 동의·Claude API 키, 실패/저장 상태는 실제 구현의 동작을 유지한다. 연결 및 수업 연습은 기존 접근 가능한 dialog를 사용한다. 이 작업은 모든 화면이 픽셀 단위로 동일하다는 인증이 아니다.

## 검증

- `npm run build`: Next.js 운영 빌드 통과.
- `npm run lint`: 오류 0, 수정 범위 밖 기존 경고 4개.
- `npm run test:v2`: 브라우저 → Next API → 격리 저장소 전체 통과. 프로세스 종료와 테스트 데이터 정리 확인.
- 학습자 가입/언어 선택/말하기 중심 레벨 체크, 영어·일본어·태국어·스페인어, 4단계×8상황.
- 한 마이크 → STT 자동 언어 → 번역, 번역 양방향 저장·중복 방지·동의 변경/삭제 중 요청 보호.
- AI 여러 차례 대화 → 이전 답변 듣기/저장 → 말하기 연습 → 다음 복습일.
- 개인 모델/학습자 격리, CSRF, 소유자 관리자 검수·게시·게시 취소, revision 충돌, 로그아웃.
- 360/390/768/1440px: 문서·앱 가로 넘침 없음, 하단 메뉴가 화면 안에 위치, 앱 폭 제한, 시안 색·폰트·SVG 아이콘 확인.
- 실제 캡처에서 스터디·레벨·상황·번역·대화 확인. Next.js 개발자 배지는 테스트 캡처에서만 숨긴다.

AI/음성/개인 모델 공급자는 격리 fixture다. 실제 공급자 품질·마이크 기기·모바일 브라우저를 이번 검증으로 확인했다고 주장하지 않는다. 승인된 머지 후 운영 배포와 실제 접속 확인이 남는다.
